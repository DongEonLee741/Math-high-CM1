조립제법 심화

예제 7

조립제법을 이용하여 다음 나눗셈의 몫과 나머지를 구하시오.

\((2x^3 + 3x^2 - x + 2) \div (2x + 1)\)
▶ 풀이 보기

\(2x + 1 = 2\!\left(x + \dfrac{1}{2}\right)\)이므로 \(x + \dfrac{1}{2} = 0\)에서 \(x = -\dfrac{1}{2}\)

\(\textcolor{#E74C3C}{-\frac{1}{2}}\) 23\(-1\)2
\(\textcolor{#E67E22}{-1}\) \(\textcolor{#E67E22}{-1}\) \(\textcolor{#E67E22}{1}\)
22\(-2\) \(\textcolor{#E74C3C}{3}\)

이것을 식으로 나타내면

\(2x^3 + 3x^2 - x + 2 = \left(x + \dfrac{1}{2}\right)(2x^2 + 2x - 2) + 3\)   ⋯ ❶

\(= \left(x + \dfrac{1}{2}\right) \cdot 2(x^2 + x - 1) + 3\)

\(= (2x + 1)(x^2 + x - 1) + 3\)   ⋯ ❷

\(\therefore\) 몫: \(x^2 + x - 1\),   나머지: \(3\)

비주얼 개념 조립제법: \((2x^3 + 3x^2 - x + 2) \div (2x + 1)\)

\(\textcolor{#E74C3C}{-\frac{1}{2}}\) 2 3 \(-1\) 2
\(\textcolor{#E67E22}{-1}\) \(\textcolor{#E67E22}{-1}\) \(\textcolor{#E67E22}{1}\)
\(\textcolor{#2980B9}{2}\) \(\textcolor{#2980B9}{2}\) \(\textcolor{#2980B9}{-2}\) \(\textcolor{#E74C3C}{3}\)
❶ \(\left(x + \dfrac{1}{2}\right)(2x^2 + 2x - 2) + 3\)
\(= \left(x + \dfrac{1}{2}\right) \cdot 2(x^2 + x - 1) + 3\)
❷ \(= (2x + 1)(\textcolor{#27AE60}{x^2 + x - 1}) + 3\)
\(\therefore\) 몫: \(\boldsymbol{x^2 + x - 1}\),   나머지: \(\boldsymbol{3}\)
나누는 식의 일차항의 계수가 1이 아닌 경우!
\(2x + 1 = 2\!\left(x + \dfrac{1}{2}\right)\)이므로 \(x = \textcolor{#E74C3C}{-\dfrac{1}{2}}\)
Step 1: 첫째 계수 내림
첫째 계수 \(\textcolor{#2980B9}{2}\)를 그대로 내린다.
Step 2: 곱하고 더하기 반복
\(-\frac{1}{2} \times 2 = -1\),   \(3 + (-1) = 2\)
\(-\frac{1}{2} \times 2 = -1\),   \(-1 + (-1) = -2\)
\(-\frac{1}{2} \times (-2) = 1\),   \(2 + 1 = \textcolor{#E74C3C}{3}\) ← 나머지
Step 3: 식 변환 (❶ → ❷)
❶ \(x + \frac{1}{2}\)로 나눈 몫: \(2x^2 + 2x - 2\)
❷ \(2x + 1\)로 나눈 몫: \(\textcolor{#27AE60}{x^2 + x - 1}\) (÷2)
\(\therefore\) 몫: \(\boldsymbol{x^2 + x - 1}\),   나머지: \(\boldsymbol{3}\)
TIP: 일차항 계수가 1이 아니면, 조립제법 몫을 일차항 계수로 나누어야 실제 몫!
1 / 5
참고
❶에서 \(2x^2 + 2x - 2\)는 \(2x^3 + 3x^2 - x + 2\)를 \(x + \dfrac{1}{2}\)로 나누었을 때의 몫이고,
❷에서 \(x^2 + x - 1\)은 \(2x^3 + 3x^2 - x + 2\)를 \(2x + 1\)로 나누었을 때의 몫이다.
❶, ❷ 두 경우 모두 나머지는 \(3\)으로 같다.
문제 11 조립제법을 이용하여 다음 나눗셈의 몫과 나머지를 구하시오.
⑴ \((4x^3 - x + 5) \div (2x - 1)\)
⑵ \((3x^3 - 8x^2 - 2x + 1) \div (3x - 2)\)
▶ 정답 확인
정답
⑴ 몫: \(2x^2 + x\),   나머지: \(5\)

⑵ 몫: \(x^2 - 2x - 2\),   나머지: \(-3\)
문제 12 밑면의 반지름의 길이가 \(A\)이고 높이가 \(2x + 1\)인 원기둥 모양의 기름 탱크의 부피가 \((2x^3 + 13x^2 + 24x + 9)\pi\)일 때, 다항식 \(A\)를 구하시오. (단, \(x > 0\)이고, 탱크의 두께는 무시한다.)
▶ 정답 확인
정답
\(\pi A^2(2x + 1) = (2x^3 + 13x^2 + 24x + 9)\pi\)에서
\(A^2 = \dfrac{2x^3 + 13x^2 + 24x + 9}{2x + 1}\)

조립제법으로 나누면 \(A^2 = x^2 + 6x + 9 = (x + 3)^2\)
\(x > 0\)이므로 \(\boldsymbol{A = x + 3}\)

문제 1 두 다항식 \(A = x^2 - xy + y^2\), \(B = 2x^2 + xy - 2y^2\)일 때, 다음 등식을 만족시키는 다항식 \(X\)를 구하시오.
⑴ \(2A - X = 3B\)
⑵ \(A - 2(X + B) = 2A + B\)
▶ 정답 확인
정답
⑴ \(X = 2A - 3B = -4x^2 - 5xy + 8y^2\)

⑵ \(X = -\dfrac{1}{2}(A + 3B) = -\dfrac{7}{2}x^2 - xy + \dfrac{5}{2}y^2\)
문제 2 다음 식의 값을 구하시오.
⑴ \(a + b + c = 7\), \(ab + bc + ca = 4\)일 때, \(a^2 + b^2 + c^2\)의 값
⑵ \(x + y = 4\), \(xy = -2\)일 때, \(x^3 + y^3\)의 값
⑶ \(x - y = 1\), \(x^2 + y^2 = 5\)일 때, \(x^3 - y^3\)의 값
⑷ \(x + y = 2\), \(x^2 - xy + y^2 = 3\)일 때, \(x^3 + y^3\)의 값
⑸ \(x - y = -1\), \(xy = 3\)일 때, \(x^3 - y^3\)의 값
▶ 정답 확인
정답
⑴ \(41\)    ⑵ \(88\)    ⑶ \(7\)    ⑷ \(6\)    ⑸ \(-10\)
문제 3 다항식 \(4x^3 + 4x^2 + 3x - 1\)을 다항식 \(A\)로 나누었을 때의 몫은 \(2x + 1\)이고, 나머지는 \(-2x - 3\)이다. 이때 다항식 \(A\)를 구하시오.
▶ 정답 확인
정답
\(4x^3 + 4x^2 + 3x - 1 = A(2x + 1) + (-2x - 3)\)에서
\(A(2x + 1) = 4x^3 + 4x^2 + 5x + 2\)
조립제법으로 나누면 \(\boldsymbol{A = 2x^2 + x + 2}\)
문제 4 모든 모서리의 길이의 합이 \(36\) cm이고, 겉넓이가 \(52\) cm\(^2\)인 직육면체가 있다. 이때 대각선 \(AG\)의 길이를 구하시오.
▶ 정답 확인
정답
세 모서리 \(a, b, c\)에 대해
\(4(a + b + c) = 36\)이므로 \(a + b + c = 9\)
\(2(ab + bc + ca) = 52\)이므로 \(ab + bc + ca = 26\)
\(a^2 + b^2 + c^2 = (a + b + c)^2 - 2(ab + bc + ca) = 81 - 52 = 29\)
\(\therefore\; \overline{AG} = \sqrt{a^2 + b^2 + c^2} = \boldsymbol{\sqrt{29}}\) cm
문제 5 \(x + y + z = 0\)일 때, \(\dfrac{(x + y)(y + z)(z + x)}{xyz}\)의 값을 구하시오. (단, \(xyz \ne 0\))
▶ 정답 확인
정답
\(x + y + z = 0\)에서
\(x + y = -z\),   \(y + z = -x\),   \(z + x = -y\)
\(\therefore\; \dfrac{(x + y)(y + z)(z + x)}{xyz} = \dfrac{(-z)(-x)(-y)}{xyz} = \dfrac{-xyz}{xyz} = \boldsymbol{-1}\)

🔍 수학으로 생각 넓히기

가로의 길이가 \(3x^2 - x + 5\), 세로의 길이가 \(x^2 + 2\)인 직사각형 모양의 땅이 있다. 이 땅을 세 정사각형 A, B, C와 직사각형 D로 나눈 후 A와 B에는 자동차 야영장, C에는 물놀이장, D에는 놀이 시설을 만들려고 한다. 이때 D의 넓이를 구하시오. (단, \(x > -1\)이고, 경계선의 넓이는 생각하지 않는다.)
