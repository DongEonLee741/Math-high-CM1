항등식의 성질

탐구 열기

다음 등식 중에서 항등식인 것을 찾아보자.

ㄱ. \(x^2 - 3x = 0\)

ㄴ. \(x^2 - 3x = x(x - 3)\)

키우기   등식 \(ax^2 + bx + c = 0\)이 \(x\)에 대한 항등식이 되려면 \(a\), \(b\), \(c\)는 각각 어떤 값이어야 할까?

방정식

\(x^2 - 3x = 0\)

\(x=0\) 또는 \(x=3\)일 때만 성립

특정 값에서만 참 ✗

항등식

\(x^2 - 3x = x(x-3)\)

\(x\)에 어떤 값을 넣어도 항상 성립

모든 값에서 참 ✓

비주얼 개념 항등식의 성질 ❶ ❷ 유도

성질 ❶
등식 \(ax^2 + bx + c = 0\)이 \(x\)에 대한 항등식이 되려면?
항등식이면 \(x\)에 어떤 값을 넣어도 성립 → \(x=0\), \(1\), \(-1\)을 대입해 봅시다.
\(\textcolor{#8E44AD}{x = 0}\)을 대입하면
\(\textcolor{#E74C3C}{a} \cdot \textcolor{#8E44AD}{0}^2 + \textcolor{#2980B9}{b} \cdot \textcolor{#8E44AD}{0} + \textcolor{#27AE60}{c} = 0\)
∴ \(\textcolor{#27AE60}{c = 0}\)
\(\textcolor{#27AE60}{c = 0}\)이므로 \(\textcolor{#E74C3C}{a}x^2 + \textcolor{#2980B9}{b}x = 0\)
\(\textcolor{#8E44AD}{x = 1}\) 대입 → \(\textcolor{#E74C3C}{a} + \textcolor{#2980B9}{b} = 0\)  …… ①
\(\textcolor{#8E44AD}{x = -1}\) 대입 → \(\textcolor{#E74C3C}{a} - \textcolor{#2980B9}{b} = 0\)  …… ②
①+②: \(2\textcolor{#E74C3C}{a} = 0\) → \(\textcolor{#E74C3C}{a = 0}\)
①에서: \(\textcolor{#2980B9}{b} = 0\)
∴ \(\textcolor{#E74C3C}{a = 0},\; \textcolor{#2980B9}{b = 0},\; \textcolor{#27AE60}{c = 0}\)
거꾸로 \(a=0\), \(b=0\), \(c=0\)이면
등식 \(ax^2+bx+c = 0\)은 \(0=0\)이 되어
\(x\)에 어떤 값을 대입해도 항상 성립 → 항등식이다.
성질 ❷
등식 \(ax^2 + bx + c = a'x^2 + b'x + c'\)이 항등식이 되려면?
\(\textcolor{#E74C3C}{a}x^2 + \textcolor{#2980B9}{b}x + \textcolor{#27AE60}{c} = \textcolor{#E74C3C}{a'}x^2 + \textcolor{#2980B9}{b'}x + \textcolor{#27AE60}{c'}\)
우변을 좌변으로 이항하여 정리하면
\((\textcolor{#E74C3C}{a-a'})x^2 + (\textcolor{#2980B9}{b-b'})x + (\textcolor{#27AE60}{c-c'}) = 0\)
이것이 \(x\)에 대한 항등식이므로
↑ 위의 성질 ❶에 의하여
\(\textcolor{#E74C3C}{a - a'} = 0\),  \(\textcolor{#2980B9}{b - b'} = 0\),  \(\textcolor{#27AE60}{c - c'} = 0\)
∴ \(\textcolor{#E74C3C}{a = a'},\; \textcolor{#2980B9}{b = b'},\; \textcolor{#27AE60}{c = c'}\)
양변에서 같은 차수의 계수끼리 같아야 한다!
거꾸로 \(a=a'\), \(b=b'\), \(c=c'\)이면
\((a-a')x^2+(b-b')x+(c-c') = 0\)은 \(0=0\)이 되어 항등식이다.
→ 따라서 \(ax^2+bx+c = a'x^2+b'x+c'\)도 항등식이다.
\(x\)에 어떤 수를 대입해도 되지만, \(0\), \(1\), \(-1\)을 대입하면 계산이 간단해요.
\(x=0\)을 대입하면 \(x^2\)항과 \(x\)항이 모두 사라져 바로 \(c=0\)을 알 수 있습니다.
\(c=0\)을 이용하면 \(x=1\), \(x=-1\) 대입으로 \(a, b\)에 대한 연립방정식을 만들 수 있습니다.
연립방정식을 풀면 모든 계수가 0이어야 합니다. 이것이 항등식의 성질 ❶입니다.
역방향도 성립합니다. 모든 계수가 0이면 등식은 항상 참이므로 항등식입니다.
이제 성질 ❷입니다. 양변에서 같은 차수의 항을 색으로 대응시켜 봅시다.
우변을 모두 좌변으로 이항하면 \((\text{...}) = 0\) 꼴이 됩니다.
이 등식이 항등식이므로, 방금 배운 성질 ❶을 적용합니다.
결론: 양변에서 같은 차수의 계수끼리 같아야 항등식이 됩니다. 이것이 성질 ❷입니다.
역방향도 성립합니다. 대응하는 계수가 모두 같으면 항등식입니다.

개념 항등식의 성질

  • ❶ \(ax^2 + bx + c = 0\)이 \(x\)에 대한 항등식이면 \(a = 0\), \(b = 0\), \(c = 0\)이다.
         또 \(a = 0\), \(b = 0\), \(c = 0\)이면 \(ax^2 + bx + c = 0\)은 \(x\)에 대한 항등식이다.
  • ❷ \(ax^2 + bx + c = a'x^2 + b'x + c'\)이 \(x\)에 대한 항등식이면 \(a = a'\), \(b = b'\), \(c = c'\)이다.
         또 \(a = a'\), \(b = b'\), \(c = c'\)이면 \(ax^2 + bx + c = a'x^2 + b'x + c'\)은 \(x\)에 대한 항등식이다.

비주얼 개념 등식 \(ax^2 + bx + 2 = 3x^2 - 4x + c\)가 항등식이면?

\(\textcolor{#E74C3C}{a}\,x^2 + \textcolor{#2980B9}{b}\,x + \textcolor{#27AE60}{2} = \textcolor{#E74C3C}{3}\,x^2 + \textcolor{#2980B9}{(-4)}\,x + \textcolor{#27AE60}{c}\)
항등식의 성질 ❷에 의하여 양변의 계수를 비교하면
\(\textcolor{#E74C3C}{a} = \textcolor{#E74C3C}{3}\),   \(\textcolor{#2980B9}{b} = \textcolor{#2980B9}{-4}\),   \(\textcolor{#27AE60}{c} = \textcolor{#27AE60}{2}\)
양변에서 같은 차수의 항을 색으로 대응시켜 봅시다.
항등식의 성질 ❷: 양변의 동류항의 계수가 같아야 합니다.
\(x^2\)의 계수, \(x\)의 계수, 상수항을 각각 비교하면 \(a\), \(b\), \(c\)의 값을 알 수 있습니다.

미정계수법

개념 미정계수법

항등식의 성질을 이용하여 주어진 등식에서 미지의 계수와 상수항을 정하는 방법을 미정계수법이라 한다.

  • 방법 1   양변의 동류항의 계수를 비교하여 계수를 정하는 방법
  • 방법 2   문자에 적당한 수를 대입하여 계수를 정하는 방법
예제 1 — 항등식의 성질을 이용하여 미정계수 구하기

다음 등식이 \(x\)에 대한 항등식이 되게 하는 상수 \(a\), \(b\), \(c\)의 값을 구하시오.

\(a(x - 1)^2 + b(x - 1) + c = x^2 + 2x + 3\)

풀이 — 양변의 동류항의 계수 비교하기
좌변을 전개하여 정리하면
\(a(x^2 - 2x + 1) + b(x - 1) + c = x^2 + 2x + 3\)
\(ax^2 - 2ax + a + bx - b + c = x^2 + 2x + 3\)
\(ax^2 + (b - 2a)x + (a - b + c) = x^2 + 2x + 3\)
항등식의 성질을 이용하여 양변의 동류항의 계수를 비교하면
\(a = 1\)    ⋯ ㉠
\(b - 2a = 2\)    ⋯ ㉡
\(a - b + c = 3\)    ⋯ ㉢
㉠, ㉡, ㉢을 연립하여 풀면   \(\boldsymbol{a = 1,\; b = 4,\; c = 6}\)
