다항식의 정리

탐구 열기

다음 두 다항식의 차수를 구하고, 차수를 구하기 편리한 것은 어느 것인지 말해 보자.

⑴ \(3x^2 + 1 + 4x^3 + x^5 + 4x + 2x^4\)
⑵ \(x^5 + 2x^4 + 4x^3 + 3x^2 + 4x + 1\)
▶ 정답 확인
정답
⑴, ⑵ 모두 차수는 5이다.   내림차순으로 정리된 ⑵가 차수를 구하기 편리하다.

개념 다항식의 정리

  • 다항식을 한 문자에 대하여 차수가 높은 항부터 낮은 항의 순서로 나타내는 것을 그 문자에 대하여 '내림차순으로 정리한다'고 한다.
  • 차수가 낮은 항부터 높은 항의 순서로 나타내는 것을 그 문자에 대하여 '오름차순으로 정리한다'고 한다.
다항식에서 상수항의 차수는 0으로 생각한다.

⑴ \(2x^2 + 3x + 1 + x^3\)
⑵ \(xy + 5x + 2y^3 - x^2y - 2y + 1\)
▶ 정답 확인
정답
⑴ \(x^3 + 2x^2 + 3x + 1\)
⑵ \(-x^2y + (y + 5)x + 2y^3 - 2y + 1\)

다항식의 덧셈과 뺄셈

개념 다항식의 덧셈과 뺄셈

  • 덧셈: 동류항끼리 모아서 정리한다.
  • 뺄셈: 빼는 식의 각 항의 부호를 바꾸어서 더한다.
\(A - B = A + (-B)\)
동류항이란 문자와 차수가 각각 같은 항을 말한다.

예제 — 다항식의 덧셈과 뺄셈하기

두 다항식 \(A = x^3 - 2x^2 + 1\), \(B = -2x^3 - 3x + 5\) 일 때, 다음을 계산하시오.

⑴ \(A + B\)
⑵ \(A - B\)
풀이
⑴ \(A + B = (x^3 - 2x^2 + 1) + (-2x^3 - 3x + 5)\)
\(= (1-2)x^3 - 2x^2 - 3x + (1+5)\)
\(= \boldsymbol{-x^3 - 2x^2 - 3x + 6}\)
⑵ \(A - B = (x^3 - 2x^2 + 1) - (-2x^3 - 3x + 5)\)
\(= (x^3 - 2x^2 + 1) + (2x^3 + 3x - 5)\)
\(= (1+2)x^3 - 2x^2 + 3x + (1-5)\)
\(= \boldsymbol{3x^3 - 2x^2 + 3x - 4}\)
스스로 하기 — 다항식의 덧셈과 뺄셈

⑴ \(A + B\)
⑵ \(A - B\)
▶ 정답 확인
정답
⑴ \(3x^3 + x^2 - 3x - 5\)
⑵ \(-3x^3 + x^2 - 5x - 1\)

다항식의 덧셈에 대한 성질

개념 다항식의 덧셈에 대한 성질

세 다항식 A, B, C에 대하여

❶ 교환법칙 \(A + B = B + A\)
❷ 결합법칙 \((A + B) + C = A + (B + C)\)

덧셈에 대한 결합법칙이 성립하므로 (A+B)+C, A+(B+C)를 괄호를 생략하여 A+B+C로 나타내기도 한다.

예제 — 다항식의 덧셈에 대한 성질 이해하기

두 다항식 A, B가

\(A = x^3 + x^2 + 1, \quad B = 3x^3 - x^2 + 2x + 4\)

일 때, \((2A + 3B) + (A - 4B)\)를 계산하시오.

STEP 1   식을 정리한 후 다항식을 대입한다.
\((2A + 3B) + (A - 4B) = 2A + 3B + A - 4B\)
\(= 2A + A + 3B - 4B \quad\) ... 교환법칙
\(= (2A + A) + (3B - 4B) \quad\) ... 결합법칙
\(= 3A - B\)
STEP 2   A, B를 대입하여 계산한다.
\(= 3(x^3 + x^2 + 1) - (3x^3 - x^2 + 2x + 4)\)
\(= (3x^3 + 3x^2 + 3) + (-3x^3 + x^2 - 2x - 4)\)
\(= (3-3)x^3 + (3+1)x^2 - 2x + (3-4) = \boldsymbol{4x^2 - 2x - 1}\)

⑴ \((A - 2B) + (3A + B)\)
