인수정리

개념 인수정리

다항식 \(P(x)\)에 대하여

  • ❶ \(P(a) = 0\)이면 \(P(x)\)는 일차식 \(x - a\)로 나누어떨어진다.
  • ❷ \(P(x)\)가 일차식 \(x - a\)로 나누어떨어지면 \(P(a) = 0\)이다.
나머지정리에서 \(P(a) = 0\)이면 나머지가 \(0\)이므로 \(P(x)\)는 \(x - a\)로 나누어떨어진다. 즉, \(x - a\)는 \(P(x)\)의 인수이다.

탐구 인수 탐색기

\(P(x) = x^3 - 2x^2 - x + 2\)에서 \(P(a) = 0\)이 되는 \(a\)를 찾으면 \((x - a)\)는 인수!

a 값을 대입해 보세요:

발견한 인수: 0 / 3
예제 4 — 인수정리를 이용하여 계수 구하기

다항식 \(P(x) = x^3 - ax + 4\)가 \(x - 2\)로 나누어떨어지게 하는 상수 \(a\)의 값을 구하시오.

풀이
\(P(x)\)가 \(x - 2\)로 나누어떨어지면 인수정리에 의하여
\(P(2) = 0\)
\(P(2) = 8 - 2a + 4 = -2a + 12 = 0\)이므로
\(-2a + 12 = 0\), 즉 \(\boldsymbol{a = 6}\)
스스로 하기

일차식 \(x - 1\)이 다항식 \(P(x) = x^3 - 3x^2 + ax + 7\)의 인수가 되도록 하는 상수 \(a\)의 값을 구하시오.

▶ 정답 확인
정답
\(x - 1\)이 \(P(x)\)의 인수가 되려면 인수정리에 의하여
\(P(1) = 0\)
\(1 - 3 + a + 7 = 0\)에서 \(a + 5 = 0\)
\(\therefore\; \boldsymbol{a = -5}\)
문제 1 일차식 \(x + 2\)가 다항식 \(P(x) = x^3 + 5x^2 + 2ax + a\)의 인수가 되도록 하는 상수 \(a\)의 값을 구하시오.
▶ 정답 확인
정답
\(P(-2) = -8 + 20 - 4a + a = 0\)에서
\(-3a + 12 = 0\)
\(\therefore\; \boldsymbol{a = 4}\)
문제 2 다항식 \(P(x) = x^3 + ax^2 + bx - 2\)가 \((x - 1)(x - 2)\)로 나누어떨어지게 하는 상수 \(a\), \(b\)의 값을 구하시오.
▶ 정답 확인
정답
\(P(1) = 0\)에서 \(1 + a + b - 2 = 0\) → \(a + b = 1\) ⋯ ㉠
\(P(2) = 0\)에서 \(8 + 4a + 2b - 2 = 0\) → \(4a + 2b = -6\) ⋯ ㉡
㉠, ㉡을 풀면 \(\boldsymbol{a = -4,\; b = 5}\)

스스로 확인하기

2. 항등식과 나머지정리 전체를 복습합니다. 항등식, 미정계수법, 나머지정리, 인수정리를 활용하여 문제를 풀어 보세요.

문제 3 다음 등식이 \(x\)에 대한 항등식이 되게 하는 상수 \(a\), \(b\), \(c\)의 값을 구하시오.
⑴ \(x^3 + ax^2 + bx + 3 = x(x^2 - 1) + c\)
⑵ \(ax(x - 1) + b(x - 1)(x + 1) + cx(x + 1) = x^2 - 2x + 3\)
▶ 정답 확인
정답
⑴ \(\boldsymbol{a = 0,\; b = -1,\; c = 3}\)

⑵ 방법2(대입)로 풀면: \(x = 0\) → \(-b = 3\), \(x = 1\) → \(2c = 2\), \(x = -1\) → \(2a = 6\)
\(\boldsymbol{a = 3,\; b = -3,\; c = 1}\)
문제 4 다항식 \(P(x)\)를 \(x - 1\)로 나누었을 때의 나머지가 \(-10\)이고, \(x - 2\)로 나누었을 때의 나머지가 \(10\)이다. \(P(x)\)를 \(x^2 - 3x + 2\)로 나누었을 때의 나머지를 구하시오.
▶ 정답 확인
정답
\(x^2 - 3x + 2 = (x - 1)(x - 2)\)이므로 나머지를 \(ax + b\)로 놓으면
\(P(1) = -10\) → \(a + b = -10\) ⋯ ㉠
\(P(2) = 10\) → \(2a + b = 10\) ⋯ ㉡
풀면 \(a = 20\), \(b = -30\)
\(\therefore\) 나머지: \(\boldsymbol{20x - 30}\)
문제 5 이차식 \((x - 1)^2\)이 다항식 \(x^3 - x^2 + ax + b\)의 인수일 때, 상수 \(a\), \(b\)의 값을 구하시오.
▶ 정답 확인
정답
\(P(x) = x^3 - x^2 + ax + b\)로 놓으면 \((x - 1)^2\)이 인수이므로
\(P(x) = (x - 1)^2(x + k)\) (k는 상수)
\(x^3\)의 계수 비교: \(1 = 1\) ✓, \(x^2\)의 계수: \(k - 2 = -1\) → \(k = 1\)
\(P(x) = (x - 1)^2(x + 1) = x^3 - x^2 - x + 1\)
\(\therefore\; \boldsymbol{a = -1,\; b = 1}\)
문제 6 다항식 \(x^6 + x^4 + 3x\)를 \(x + 1\)로 나누었을 때의 몫을 \(Q(x)\)라 할 때, \(Q(x)\)를 \(x - 1\)로 나누었을 때의 나머지를 구하시오.
▶ 정답 확인
정답
\(P(x) = x^6 + x^4 + 3x\)로 놓으면
\(P(x) = (x + 1)Q(x) + R\)에서 \(R = P(-1) = 1 + 1 - 3 = -1\)
\((x + 1)Q(x) = x^6 + x^4 + 3x + 1\)
\(Q(x)\)를 \(x - 1\)로 나눈 나머지 = \(Q(1)\)
\((1 + 1)Q(1) = 1 + 1 + 3 + 1 = 6\)
\(Q(1) = 3\)
\(\therefore\) 나머지: \(\boldsymbol{3}\)
문제 7 다항식 \(f(x) = 2x^3 + ax^2 + bx + c\)가 다음 조건을 만족시킬 때, \(a + b + c\)의 값을 구하시오. (단, \(a\), \(b\), \(c\)는 상수)

(가) \(2x + 1\)은 \(f(x)\)의 인수이다.

(나) \(f(x)\)를 \(x^2 + x - 1\)로 나눈 나머지가 \(2x + 1\)이다.

▶ 정답 확인
정답
(나)에서 \(f(x) = (x^2 + x - 1)(2x + d) + 2x + 1\)로 놓으면 (최고차항 계수 비교: \(Q(x) = 2x + d\))
전개하면 \(f(x) = 2x^3 + (d+2)x^2 + dx + (1-d)\)
\(\therefore\; a = d+2,\; b = d,\; c = 1-d\)

(가)에서 \(f\!\left(-\tfrac{1}{2}\right) = 0\):
\(-\tfrac{1}{4} + \tfrac{d+2}{4} - \tfrac{d}{2} + (1-d) = 0\) → \(-5d + 5 = 0\) → \(d = 1\)

\(a = 3,\; b = 1,\; c = 0\)
\(\boldsymbol{a + b + c = 4}\)

🔍 수학으로 생각 넓히기

\(x^3\)의 계수가 \(1\)인 삼차다항식 \(P(x)\)에 대하여 \(P(-1) = P(1) = P(2) = 3\)일 때, \(P(-2)\)의 값을 구해 보자.
