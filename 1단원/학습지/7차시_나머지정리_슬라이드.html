나머지정리

탐구 열기

다항식 \(P(x) = x^2 + 3x - 6\)에 대하여 물음에 답해 보자.

⑴ \(P(x)\)를 \(x - 2\)로 나누었을 때의 나머지를 구하시오.
⑵ \(P(2)\)를 구하고, ⑴에서 구한 나머지와 비교하시오.

키우기   다항식을 일차식으로 직접 나누지 않고도 나머지를 구할 수 있는 방법은 무엇일까?

비주얼 개념 나머지정리는 왜 성립할까?

다항식 \(\textcolor{#E74C3C}{P(x)}\)를 일차식 \(\textcolor{#2980B9}{x-a}\)로 나누면
\(\textcolor{#E74C3C}{P(x)} = \textcolor{#2980B9}{(x-a)} \cdot \textcolor{#E67E22}{Q(x)} + \textcolor{#27AE60}{R}\)
(\(\textcolor{#E67E22}{Q(x)}\): 몫,  \(\textcolor{#27AE60}{R}\): 나머지(상수))
이 항등식의 양변에 \(\textcolor{#8E44AD}{x = a}\)를 대입하면
\(\textcolor{#E74C3C}{P(\textcolor{#8E44AD}{a})} = (\textcolor{#8E44AD}{a}-a) \cdot \textcolor{#E67E22}{Q(\textcolor{#8E44AD}{a})} + \textcolor{#27AE60}{R}\)
\((\textcolor{#8E44AD}{a} - a) = \textcolor{#E74C3C}{0}\) 이므로
\(\textcolor{#E74C3C}{P(a)} = \textcolor{#E74C3C}{0} \cdot \textcolor{#E67E22}{Q(a)} + \textcolor{#27AE60}{R} = \textcolor{#27AE60}{R}\)
\(\textcolor{#E74C3C}{P(a)} = \textcolor{#27AE60}{R}\)  (나머지)
나눗셈을 직접 계산하지 않고
\(\textcolor{#8E44AD}{x=a}\)를 대입하기만 하면 나머지를 구할 수 있다!
다항식의 나눗셈 관계식: (나누어지는 식) = (나누는 식) × (몫) + (나머지)
이 등식은 항등식이므로 어떤 \(x\)를 넣어도 성립합니다. \(x=a\)를 넣어 봅시다.
\((a-a) = 0\)이 되어 몫 부분이 통째로 사라집니다!
나머지 \(R\)은 곧 \(P(a)\)! 이것이 나머지정리의 핵심입니다.

탐구 나머지 비교기

\(P(x) = x^2 + 3x - 6\)을 \(x - a\)로 나눈 나머지와 \(P(a)\)를 비교해 봅시다.

\(a\) 값을 선택하세요:

개념 나머지정리

다항식 \(P(x)\)를 일차식 \(x - a\)로 나누었을 때의 나머지를 \(R\)이라 하면

\(R = P(a)\)

참고: \(P(x)\)를 \(ax + b\)로 나누었을 때의 나머지는 \(P\!\left(-\dfrac{b}{a}\right)\)

비주얼 개념 \(P(x) = x^3 + 3x^2 - 2x + 1\)을 \(x - 2\)로 나누었을 때의 나머지

\(P(\textcolor{#E74C3C}{x})\)에 \(\textcolor{#E74C3C}{x} = \textcolor{#E74C3C}{2}\)를 대입하면
\(P(\textcolor{#E74C3C}{2}) = \textcolor{#E74C3C}{2}^3 + 3 \times \textcolor{#E74C3C}{2}^2 - 2 \times \textcolor{#E74C3C}{2} + 1\)
\(= 8 + 12 - 4 + 1 = \boldsymbol{17}\)
나머지는 \(\boldsymbol{17}\)이네.
나머지정리: \(P(x)\)를 \(x - a\)로 나눈 나머지 = \(P(a)\)
\(x - 2\)로 나누므로 \(a = 2\). \(P(2)\)를 계산합니다.
직접 나누지 않고 대입만으로 나머지 \(17\)을 구했습니다!

예제 2 — 다항식을 \(ax + b\)로 나누었을 때의 나머지 구하기

다항식 \(P(x) = 2x^3 - 3x^2 + 4\)를 \(2x + 1\)로 나누었을 때의 나머지를 구하시오.

풀이
\(P(x)\)를 \(2x + 1\)로 나누었을 때의 나머지 \(R\)은
\(R = P\!\left(-\dfrac{1}{2}\right) = 2 \times \left(-\dfrac{1}{2}\right)^3 - 3 \times \left(-\dfrac{1}{2}\right)^2 + 4\)
\(= -\dfrac{1}{4} - \dfrac{3}{4} + 4 = \boldsymbol{3}\)
문제 2 다항식 \(P(x) = 6x^3 - x + 1\)을 다음 일차식으로 나누었을 때의 나머지를 구하시오.
⑴ \(2x - 1\)
⑵ \(3x + 2\)
▶ 정답 확인
정답
⑴ \(\boldsymbol{\dfrac{5}{4}}\)     ⑵ \(\boldsymbol{-\dfrac{1}{9}}\)
예제 3 — 다항식을 이차식으로 나누었을 때의 나머지 구하기

다항식 \(P(x)\)를 \(x - 1\)로 나누었을 때의 나머지가 \(5\)이고, \(x + 2\)로 나누었을 때의 나머지가 \(-4\)이다. \(P(x)\)를 \((x - 1)(x + 2)\)로 나누었을 때의 나머지를 구하시오.

풀이
\(P(x)\)를 \((x - 1)(x + 2)\)로 나누었을 때의 몫을 \(Q(x)\), 나머지를 \(ax + b\) (\(a\), \(b\)는 상수)라 하면
\(P(x) = (x - 1)(x + 2)Q(x) + ax + b\)
\(P(1) = 5\)이므로   \(a + b = 5\)    ⋯ ㉠
\(P(-2) = -4\)이므로   \(-2a + b = -4\)    ⋯ ㉡
㉠, ㉡을 연립하여 풀면   \(a = 3\), \(b = 2\)
따라서 구하는 나머지는   \(\boldsymbol{3x + 2}\)
문제 3 다항식 \(P(x)\)를 \(x + 3\)으로 나누었을 때의 나머지가 \(-10\)이고, \(x - 2\)로 나누었을 때의 나머지가 \(40\)이다. \(P(x)\)를 \((x + 3)(x - 2)\)로 나누었을 때의 나머지를 구하시오.
▶ 정답 확인
정답
\(P(x) = (x + 3)(x - 2)Q(x) + ax + b\)로 놓으면
\(P(-3) = -10\)에서 \(-3a + b = -10\) ⋯ ㉠
\(P(2) = 40\)에서 \(2a + b = 40\) ⋯ ㉡
㉠, ㉡을 풀면 \(a = 10\), \(b = 20\)
\(\therefore\) 나머지: \(\boldsymbol{10x + 20}\)

문제 5 다항식 \(P(x) = x^3 + ax^2 - 3x + 2\)를 \(x - 3\)으로 나누었을 때, 나머지가 \(2\)이다. 이때 실수 \(a\)의 값을 구하시오.
▶ 정답 확인
정답
\(P(3) = 27 + 9a - 9 + 2 = 2\)에서 \(9a = -18\)
\(\therefore\; \boldsymbol{a = -2}\)
문제 6 다음 중에서 다항식 \(P(x) = x^3 + x^2 - 4x - 4\)의 인수를 모두 고르시오.
\(x + 2\) \(x + 1\) \(x - 1\) \(x - 2\)
▶ 정답 확인
정답
\(P(-2) = -8 + 4 + 8 - 4 = 0\) ✓
\(P(-1) = -1 + 1 + 4 - 4 = 0\) ✓
\(P(1) = 1 + 1 - 4 - 4 = -6 \ne 0\) ✗
\(P(2) = 8 + 4 - 8 - 4 = 0\) ✓
\(\therefore\) \(\boldsymbol{x + 2,\; x + 1,\; x - 2}\)
문제 7 다항식 \(P(x) = x^3 + 2x^2 - ax + 8\)이 \(x + 1\)로 나누어떨어질 때, 실수 \(a\)의 값을 구하시오.
▶ 정답 확인
정답
\(P(-1) = -1 + 2 + a + 8 = 0\)에서
\(a + 9 = 0\)
\(\therefore\; \boldsymbol{a = -9}\)
