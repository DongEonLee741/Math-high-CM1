다항식의 나눗셈

개념 다항식의 나눗셈

  • 다항식의 나눗셈은 각 다항식을 내림차순으로 정리한 다음, 자연수의 나눗셈과 같은 방법으로 계산한다.
참고   자연수의 나눗셈: \(315 \div 13\)에서 몫은 \(24\), 나머지는 \(3\)이므로 \(315 = 13 \times 24 + 3\)
다항식의 나눗셈도 같은 원리로 \(A = BQ + R\) 꼴로 나타낼 수 있다.

비주얼 개념 세로 나눗셈: \((3x^2 - 7x + 5) \div (x - 2)\)

\(\textcolor{#E74C3C}{3x}\) \(\textcolor{#27AE60}{-1}\)
\(x - 2\) \(3x^2\) \(-7x\) \(+5\)
\(\textcolor{#2980B9}{3x^2}\) \(\textcolor{#2980B9}{-6x}\)
\(\textcolor{#E67E22}{-x}\) \(\textcolor{#E67E22}{+5}\)
\(\textcolor{#8E44AD}{-x}\) \(\textcolor{#8E44AD}{+2}\)
\(\textcolor{#E74C3C}{3}\)
\(3x^2 - 7x + 5\)를 \(x - 2\)로 나누어 봅시다. 내림차순으로 정리된 상태에서 세로 나눗셈을 시작합니다.
Step 1: 첫째 항 나누기
\(\textcolor{#E74C3C}{3x^2} \div x = \textcolor{#E74C3C}{3x}\)   ← 몫의 첫째 항
Step 2: 곱하고 빼기
\((x - 2) \times 3x = \textcolor{#2980B9}{3x^2 - 6x}\)
빼면 \(\textcolor{#E67E22}{-x + 5}\) → 다음 단계로
Step 3: 둘째 항 나누기
\(\textcolor{#E67E22}{-x} \div x = \textcolor{#27AE60}{-1}\)   ← 몫의 둘째 항
Step 4: 최종 나머지
\((x - 2) \times (-1) = \textcolor{#8E44AD}{-x + 2}\)를 빼면 나머지 \(\textcolor{#E74C3C}{3}\)
\(\therefore\) 몫: \(\boldsymbol{3x - 1}\),   나머지: \(\boldsymbol{3}\)

개념 다항식의 나눗셈과 \(A = BQ + R\)

일반적으로 다항식 \(A\)를 다항식 \(B\) (\(B \ne 0\))로 나누었을 때의 몫을 \(Q\), 나머지를 \(R\)라 하면

\(A = BQ + R\)

가 성립한다. 이때 \(R\)의 차수는 \(B\)의 차수보다 낮다.

특히 \(R = 0\)일 때 \(A\)는 \(B\)로 나누어떨어진다고 한다.

TIP   나머지 \(R\)의 차수가 나누는 식 \(B\)의 차수보다 낮은지 반드시 확인하자!
예) \(B\)가 일차식이면 \(R\)은 상수, \(B\)가 이차식이면 \(R\)은 일차 이하.
참고   자연수의 나눗셈 비유
\(315 = 13 \times 24 + 3\)   (나머지 \(3 < 13\))
\(3x^2 - 7x + 5 = (x - 2)(3x - 1) + 3\)   (나머지 \(3\)의 차수 \(< x - 2\)의 차수)
카드를 탭하여 TIP 확인

비주얼 개념 \(A = BQ + R\) 꼴로 나타내기

두 다항식 \(A = x^3 + 3x^2 - x - 2\), \(B = x + 2\)에 대하여 \(A\)를 \(B\)로 나누면

  \(x^3 + 3x^2 - x - 2\)를 \(x + 2\)로 나누면
  몫: \(x^2 + x - 3\),   나머지: \(4\)
\(\therefore\; x^3 + 3x^2 - x - 2 = (x + 2)(x^2 + x - 3) + 4\)
문제 9 다항식 \(A\)를 다항식 \(B\)로 나누었을 때의 몫 \(Q\)와 나머지 \(R\)를 구하고, \(A = BQ + R\) 꼴로 나타내시오.
⑴ ⑵ 결과
⑴ \(A = 2x^3 - x^2 - 4x + 3\),   \(B = x + 1\)
⑵ \(A = 6x^3 - 3x^2 + 7x\),   \(B = x^2 + x - 1\)
▶ 정답 확인
정답
⑴ \(Q = 2x^2 - 3x - 1\), \(R = 4\)
    \(2x^3 - x^2 - 4x + 3 = (x + 1)(2x^2 - 3x - 1) + 4\)

⑵ \(Q = 6x - 9\), \(R = 22x - 9\)
    \(6x^3 - 3x^2 + 7x = (x^2 + x - 1)(6x - 9) + 22x - 9\)

조립제법

개념 조립제법

  • 다항식 \(P(x)\)를 일차식으로 나누었을 때, 계수만 이용하여 몫과 나머지를 구하는 방법을 조립제법이라 한다.
주의   조립제법은 일차식으로 나누는 나눗셈에 대해서만 이용할 수 있다.

비주얼 개념 조립제법: \((2x^3 - x^2 - 5x + 2) \div (x - 2)\)

\(\textcolor{#E74C3C}{2}\) 2 \(-1\) \(-5\) 2
\(\textcolor{#E67E22}{4}\) \(\textcolor{#27AE60}{6}\) \(\textcolor{#8E44AD}{2}\)
\(\textcolor{#2980B9}{2}\) \(\textcolor{#2980B9}{3}\) \(\textcolor{#2980B9}{1}\) \(\textcolor{#E74C3C}{4}\)
\(x - 2 = 0\)에서 \(x = \textcolor{#E74C3C}{2}\)를 왼쪽에 적고, 계수 \(2, -1, -5, 2\)를 차례로 적습니다.
Step 1: 첫째 계수 내림
첫째 계수 \(\textcolor{#2980B9}{2}\)를 그대로 내린다.
Step 2: 곱하고 더하기
\(\textcolor{#E74C3C}{2} \times 2 = \textcolor{#E67E22}{4}\),   \(-1 + \textcolor{#E67E22}{4} = \textcolor{#2980B9}{3}\)
Step 3: 곱하고 더하기
\(\textcolor{#E74C3C}{2} \times 3 = \textcolor{#27AE60}{6}\),   \(-5 + \textcolor{#27AE60}{6} = \textcolor{#2980B9}{1}\)
Step 4: 마지막 → 나머지
\(\textcolor{#E74C3C}{2} \times 1 = \textcolor{#8E44AD}{2}\),   \(2 + \textcolor{#8E44AD}{2} = \textcolor{#E74C3C}{4}\) ← 나머지
\(\therefore\) 몫: \(\boldsymbol{2x^2 + 3x + 1}\),   나머지: \(\boldsymbol{4}\)
