## 탐구 열기

> 다음은 8개의 직육면체를 붙여 한 개의 정육면체를 만드는 과정을 나타낸 것이다.
>
> 직육면체 8개의 부피의 합과 정육면체의 부피를 구하여 빈칸에 써넣어 보자.
>
> \(x^3 + 3x^2 + 3x + 1 = (x + 1)^3\)

**정답**: 직육면체 8개의 부피의 합은 \(x^3 + 3x^2 + 3x + 1\)이고, 정육면체의 한 변의 길이가 \(x + 1\)이므로 부피는 \((x + 1)^3\)이다.

---

## 핵심 개념

### 인수분해

하나의 다항식을 두 개 이상의 다항식의 곱으로 나타내는 것을 **인수분해**라 한다. 일반적으로 인수분해는 다항식의 전개 과정을 거꾸로 생각하면 된다.

따라서 앞에서 배운 곱셈 공식의 좌변과 우변을 바꾸면 다음과 같은 인수분해 공식을 얻을 수 있다.

### 중학교에서 배운 인수분해 공식

- **❶** \(a^2 + 2ab + b^2 = (a + b)^2\)
- **❷** \(a^2 - 2ab + b^2 = (a - b)^2\)
- **❸** \(a^2 - b^2 = (a + b)(a - b)\)
- **❹** \(x^2 + (a + b)x + ab = (x + a)(x + b)\)
- **❺** \(acx^2 + (ad + bc)x + bd = (ax + b)(cx + d)\)

### 인수분해 공식 (고등학교 추가)

- **❶** \(a^2 + b^2 + c^2 + 2ab + 2bc + 2ca = (a + b + c)^2\)
- **❷** \(a^3 + 3a^2b + 3ab^2 + b^3 = (a + b)^3\)
- **❸** \(a^3 - 3a^2b + 3ab^2 - b^3 = (a - b)^3\)
- **❹** \(a^3 + b^3 = (a + b)(a^2 - ab + b^2)\)
- **❺** \(a^3 - b^3 = (a - b)(a^2 + ab + b^2)\)

## 예제

### 예제: 인수분해 공식을 이용하여 인수분해하기

**지문**: 다음 식을 인수분해하시오.
⑴ \(x^3 + 9x^2 + 27x + 27\)
⑵ \(a^3 - 64b^3\)

**풀이**:

⑴ 인수분해 공식 ❷를 이용하면
\[
x^3 + 9x^2 + 27x + 27 = x^3 + 3 \cdot x^2 \cdot 3 + 3 \cdot x \cdot 3^2 + 3^3 = (x + 3)^3
\]

⑵ 인수분해 공식 ❺를 이용하면
\[
a^3 - 64b^3 = a^3 - (4b)^3 = (a - 4b)\{a^2 + a \cdot 4b + (4b)^2\} = (a - 4b)(a^2 + 4ab + 16b^2)
\]

**답**: ⑴ \((x + 3)^3\) ⑵ \((a - 4b)(a^2 + 4ab + 16b^2)\)

### 예제: \(ax^4 + bx^2 + c\)의 꼴의 다항식 인수분해하기

**지문**: 다음 식을 인수분해하시오.
⑴ \(x^4 + 3x^2 - 4\)
⑵ \(x^4 + 5x^2 + 9\)

**풀이**:

⑴ \(x^2 = X\)로 놓으면
\[
x^4 + 3x^2 - 4 = X^2 + 3X - 4 = (X - 1)(X + 4)
\]
\(X\)에 \(x^2\)을 대입하면
\[
= (x^2 - 1)(x^2 + 4) = (x + 1)(x - 1)(x^2 + 4)
\]

⑵ \(A^2 - B^2\)의 꼴로 변형하면
\[
x^4 + 5x^2 + 9 = (x^4 + 6x^2 + 9) - x^2 = (x^2 + 3)^2 - x^2
\]
\[
= (x^2 + x + 3)(x^2 - x + 3)
\]

**답**: ⑴ \((x + 1)(x - 1)(x^2 + 4)\) ⑵ \((x^2 + x + 3)(x^2 - x + 3)\)

### 예제: 공통부분을 하나의 문자로 바꾸어 인수분해하기

**지문**: 다항식 \((x^2 + 4x)(x^2 + 4x + 8) + 15\)를 인수분해하시오.

**풀이**:

\(x^2 + 4x = X\)로 놓으면
\[
(x^2 + 4x)(x^2 + 4x + 8) + 15 = X(X + 8) + 15 = X^2 + 8X + 15 = (X + 3)(X + 5)
\]

\(X\)에 \(x^2 + 4x\)를 대입하면
\[
(x^2 + 4x + 3)(x^2 + 4x + 5) = (x + 1)(x + 3)(x^2 + 4x + 5)
\]

**답**: \((x + 1)(x + 3)(x^2 + 4x + 5)\)

## 문제

### 문제 1

**지문**: 다음 식을 인수분해하시오.
⑴ \(x^2 + 4y^2 + 4z^2 + 4xy - 8yz - 4zx\)
⑵ \(a^3 - 6a^2b + 12ab^2 - 8b^3\)
⑶ \(x^3 + 27\)
⑷ \(8a^3 - 125b^3\)

**정답**:
- ⑴ \((x + 2y - 2z)^2\)
- ⑵ \((a - 2b)^3\)
- ⑶ \((x + 3)(x^2 - 3x + 9)\)
- ⑷ \((2a - 5b)(4a^2 + 10ab + 25b^2)\)

### 문제 2

**지문**: 인수분해를 이용하여 \(\dfrac{98^3 + 8}{96 \times 98 + 4}\)의 값을 구하시오.

**정답**:

분자: \(98^3 + 8 = 98^3 + 2^3 = (98 + 2)(98^2 - 98 \cdot 2 + 4) = 100(98^2 - 196 + 4)\)

분모: \(96 \times 98 + 4 = (98 - 2)(98) + 4 = 98^2 - 2 \times 98 + 4 = 98^2 - 196 + 4\)

따라서 \(\dfrac{100(98^2 - 196 + 4)}{98^2 - 196 + 4} = 100\)

### 문제 3

**지문**: 다항식 \((x^2 - 2x)(x^2 - 2x - 6) - 16\)을 인수분해하시오.

**정답**:

\(x^2 - 2x = X\)로 놓으면

\(X(X - 6) - 16 = X^2 - 6X - 16 = (X - 8)(X + 2)\)

\(X\)에 \(x^2 - 2x\)를 대입하면

\((x^2 - 2x - 8)(x^2 - 2x + 2) = (x + 2)(x - 4)(x^2 - 2x + 2)\)

### 문제 4

**지문**: 다음 식을 인수분해하시오.
⑴ \(x^4 - 10x^2 + 9\)
⑵ \(x^4 - 8x^2 + 4\)

**정답**:
- ⑴ \(x^2 = X\)로 놓으면 \(X^2 - 10X + 9 = (X - 1)(X - 9) = (x^2 - 1)(x^2 - 9) = (x + 1)(x - 1)(x + 3)(x - 3)\)
- ⑵ \(x^4 - 8x^2 + 4 = (x^4 - 4x^2 + 4) - 4x^2 = (x^2 - 2)^2 - (2x)^2 = (x^2 + 2x - 2)(x^2 - 2x - 2)\) <!-- VERIFY: 계산 검증 필요 -->

## 지도 TIP

- 직육면체 8개의 부피의 합과 이들을 이용하여 만든 정육면체의 부피가 같음을 이용하여 주어진 등식이 성립함을 직관적으로 이해하게 한다. 이를 통하여 특별한 꼴의 삼차식도 인수분해가 가능함을 알게 한다.
- 다항식의 인수분해는 주어진 다항식을 더 이상 나누어지지 않는 다항식의 곱으로 나타내는 것임을 알게 한다.
- 다항식의 인수분해는 중학교에서 학습한 내용을 토대로 고등학교에서 추가된 내용을 이해하게 한다.
- 인수분해를 이용하여 식의 값을 쉽게 계산할 수도 있음을 알게 한다.
- 공통부분을 인수분해한 경우 그 결과는 원래의 문자로 바꿔 나타내야 함을 알게 한다.
