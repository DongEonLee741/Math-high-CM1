## 핵심 개념

### 치환을 이용한 인수분해

다항식에서 **공통부분**을 하나의 문자로 치환하면 인수분해가 쉬워지는 경우가 있다.

- \(x^2 = X\)로 놓아 \(ax^4 + bx^2 + c\) 꼴을 \(aX^2 + bX + c\)로 변환
- \(A^2 - B^2\) 꼴로 변형하여 인수분해
- 공통부분 \(x^2 + px\) 등을 \(X\)로 치환

> 치환하여 인수분해한 결과는 반드시 **원래의 문자로 바꾸어** 나타내야 한다.

### 인수정리를 이용한 인수분해

삼차 이상의 다항식이 일차식을 인수로 갖는 경우, **인수정리**와 **조립제법**을 이용하여 인수분해하면 편리하다.

**인수분해 절차**:
1. 다항식 \(P(x)\)의 **상수항의 약수** \(\pm 1, \pm 2, \ldots\)를 \(x\)에 대입
2. \(P(a) = 0\)이 되는 \(a\)를 찾으면 \(P(x)\)는 \(x - a\)를 인수로 가짐 (인수정리)
3. **조립제법**을 이용하여 \(P(x) = (x - a) \cdot Q(x)\)로 분해
4. \(Q(x)\)를 추가로 인수분해

## 예제

### 예제: \(ax^4 + bx^2 + c\) 꼴의 인수분해

**지문**: 다음 식을 인수분해하시오.
- \(\text{(1)}\) \(x^4 + 3x^2 - 4\)
- \(\text{(2)}\) \(x^4 + 5x^2 + 9\)

**풀이**:

\(\text{(1)}\) \(x^2 = X\)로 놓으면
\[
x^4 + 3x^2 - 4 = X^2 + 3X - 4 = (X - 1)(X + 4)
\]
\(X\)에 \(x^2\)을 대입하면
\[
= (x^2 - 1)(x^2 + 4) = (x + 1)(x - 1)(x^2 + 4)
\]

\(\text{(2)}\) \(A^2 - B^2\) 꼴로 변형하면
\[
x^4 + 5x^2 + 9 = (x^4 + 6x^2 + 9) - x^2 = (x^2 + 3)^2 - x^2
\]
\[
= (x^2 + x + 3)(x^2 - x + 3)
\]

**답**:
- \(\text{(1)}\) \((x + 1)(x - 1)(x^2 + 4)\)
- \(\text{(2)}\) \((x^2 + x + 3)(x^2 - x + 3)\)

### 예제: 공통부분을 치환하여 인수분해하기

**지문**: 다항식 \((x^2 + 4x)(x^2 + 4x + 8) + 15\)를 인수분해하시오.

**풀이**:

\(x^2 + 4x = X\)로 놓으면
\[
(x^2 + 4x)(x^2 + 4x + 8) + 15 = X(X + 8) + 15 = X^2 + 8X + 15 = (X + 3)(X + 5)
\]
\(X\)에 \(x^2 + 4x\)를 대입하면
\[
= (x^2 + 4x + 3)(x^2 + 4x + 5) = (x + 1)(x + 3)(x^2 + 4x + 5)
\]

**답**: \((x + 1)(x + 3)(x^2 + 4x + 5)\)

### 예제: 인수정리를 이용하여 인수분해하기

**지문**: 다항식 \(P(x) = x^3 + x^2 - 10x + 8\)을 인수분해하시오.

**풀이**:

\(P(x)\)의 상수항이 \(8\)이므로 \(x\)에 \(\pm 1, \pm 2, \pm 4, \pm 8\)을 대입하여 \(P(x) = 0\)이 되는 \(x\)를 찾아보자.

\(P(1) = 1 + 1 - 10 + 8 = 0\)이므로 \(P(x)\)는 \(x - 1\)을 인수로 갖는다.

조립제법을 이용하면:

| | 1 | 1 | \(-10\) | 8 |
|---|---|---|---|---|
| 1 | | 1 | 2 | \(-8\) |
| | 1 | 2 | \(-8\) | 0 |

\[
x^3 + x^2 - 10x + 8 = (x - 1)(x^2 + 2x - 8) = (x - 1)(x - 2)(x + 4)
\]

**답**: \((x - 1)(x - 2)(x + 4)\)

## 문제

### 문제 3

**지문**: 다항식 \((x^2 - 2x)^2 - 11(x^2 - 2x) + 24\)를 인수분해하시오.

**풀이**:

\(x^2 - 2x = X\)로 놓으면
\[
X^2 - 11X + 24 = (X - 3)(X - 8)
\]
\(X\)에 \(x^2 - 2x\)를 대입하면
\[
= (x^2 - 2x - 3)(x^2 - 2x - 8) = (x + 1)(x - 3)(x + 2)(x - 4)
\]

**정답**: \((x + 1)(x - 3)(x + 2)(x - 4)\)

### 문제 5

**지문**: 다음 식을 인수분해하시오.
- \(\text{(1)}\) \(x^3 + 4x^2 + x - 6\)
- \(\text{(2)}\) \(x^4 - 5x^3 + 5x^2 + 5x - 6\)

**풀이**:

\(\text{(1)}\) \(P(x) = x^3 + 4x^2 + x - 6\)에서

\(P(1) = 1 + 4 + 1 - 6 = 0\)이므로 \(x - 1\)이 인수.

조립제법으로 \(P(x) = (x - 1)(x^2 + 5x + 6) = (x - 1)(x + 2)(x + 3)\)

\(\text{(2)}\) \(P(x) = x^4 - 5x^3 + 5x^2 + 5x - 6\)에서

\(P(1) = 1 - 5 + 5 + 5 - 6 = 0\)이므로 \(x - 1\)이 인수.

조립제법으로 \(P(x) = (x - 1)(x^3 - 4x^2 + x + 6)\)

\(Q(x) = x^3 - 4x^2 + x + 6\)에서 \(Q(2) = 8 - 16 + 2 + 6 = 0\)이므로 \(x - 2\)가 인수.

\(Q(x) = (x - 2)(x^2 - 2x - 3) = (x - 2)(x + 1)(x - 3)\)

\(\therefore P(x) = (x - 1)(x - 2)(x + 1)(x - 3) = (x + 1)(x - 1)(x - 2)(x - 3)\)

**정답**:
- \(\text{(1)}\) \((x - 1)(x + 2)(x + 3)\)
- \(\text{(2)}\) \((x + 1)(x - 1)(x - 2)(x - 3)\)

## 스스로 하기

### 스스로 하기: 공통부분 치환

**지문**: 다항식 \((x^2 - 2x)(x^2 - 2x - 6) - 16\)을 인수분해하시오.

**풀이**:

\(x^2 - 2x = X\)로 놓으면
\[
X(X - 6) - 16 = X^2 - 6X - 16 = (X - 8)(X + 2)
\]
\(X\)에 \(x^2 - 2x\)를 대입하면
\[
= (x^2 - 2x - 8)(x^2 - 2x + 2) = (x + 2)(x - 4)(x^2 - 2x + 2)
\]

**답**: \((x + 2)(x - 4)(x^2 - 2x + 2)\)

## 스스로 확인하기 (3. 인수분해)

### 1번

**지문**: 다항식 \(x^3 - ax - 15\)를 인수분해하면 \((x - 3)(x^2 + bx + 5)\)이다. 상수 \(a\), \(b\)의 값을 구하시오.

**풀이**:

\((x - 3)(x^2 + bx + 5) = x^3 + bx^2 + 5x - 3x^2 - 3bx - 15 = x^3 + (b - 3)x^2 + (5 - 3b)x - 15\)

이것이 \(x^3 - ax - 15\)와 같으므로:
- \(x^2\)의 계수: \(b - 3 = 0\) \(\Rightarrow b = 3\)
- \(x\)의 계수: \(5 - 3b = -a\) \(\Rightarrow 5 - 9 = -a\) \(\Rightarrow a = 4\)

**정답**: \(a = 4\), \(b = 3\)

### 2번

**지문**: 다음 식을 인수분해하시오.
- \(\text{(1)}\) \((x^2 - 4x)^2 - (x^2 - 4x) - 20\)
- \(\text{(2)}\) \(x^4 - 13x^2 + 36\)
- \(\text{(3)}\) \(x^3 - 3x^2 + 4x - 2\)
- \(\text{(4)}\) \(x^4 + 4x^3 - x^2 - 16x - 12\)

**정답**:
- \(\text{(1)}\) \((x - 2)^2(x + 1)(x - 5)\) <!-- VERIFY: 계산 검증 필요 -->
- \(\text{(2)}\) \((x + 2)(x - 2)(x + 3)(x - 3)\)
- \(\text{(3)}\) \((x - 1)(x^2 - 2x + 2)\)
- \(\text{(4)}\) \((x + 1)(x - 2)(x + 2)(x + 3)\) <!-- VERIFY: 계산 검증 필요 -->

### 3번

**지문**: 인수분해를 이용하여 \(\dfrac{199^3 - 7 \times 199 - 6}{197 \times 199 - 3}\)의 값을 구하시오.

**풀이**:

\(199 = x\)로 놓으면

분자: \(x^3 - 7x - 6\)

\(P(x) = x^3 - 7x - 6\)에서 \(P(-1) = -1 + 7 - 6 = 0\)이므로

\(x^3 - 7x - 6 = (x + 1)(x^2 - x - 6) = (x + 1)(x - 3)(x + 2)\)

분모: \(197 \times 199 - 3 = (x - 2)x - 3 = x^2 - 2x - 3 = (x - 3)(x + 1)\)

\[
\frac{(x + 1)(x - 3)(x + 2)}{(x - 3)(x + 1)} = x + 2 = 199 + 2 = 201
\]

**정답**: \(201\)

### 생각 넓히기 (수학으로)

**지문**: 직육면체 모양의 네 가지 블록 A, B, C, D의 밑면의 가로, 세로의 길이와 높이는 다음 표와 같다.

| 블록 | 가로 | 세로 | 높이 |
|:---:|:---:|:---:|:---:|
| A | \(x\) | \(x\) | \(x\) |
| B | \(x\) | \(x\) | \(1\) |
| C | \(x\) | \(1\) | \(1\) |
| D | \(1\) | \(1\) | \(1\) |

A 블록 1개, B 블록 5개, C 블록 8개, D 블록 4개를 모두 빈틈없이 붙여 밑면이 정사각형인 큰 직육면체를 만들었다.

- \(\text{(1)}\) 네 블록 A, B, C, D의 부피를 구하시오.
- \(\text{(2)}\) 큰 직육면체의 부피를 구하시오.
- \(\text{(3)}\) 큰 직육면체의 모든 모서리의 길이가 \(x\)에 대한 일차식일 때, 이 직육면체의 높이를 구하시오. (단, 일차식에서 \(x\)의 계수는 모두 1이다.)

**정답**:
- \(\text{(1)}\) A: \(x^3\), B: \(x^2\), C: \(x\), D: \(1\)
- \(\text{(2)}\) \(x^3 + 5x^2 + 8x + 4\)
- \(\text{(3)}\) 밑면이 정사각형이므로 밑면의 한 변의 길이는 \(x + 2\)이고, 높이는 \(x + 1\)이다.

**풀이** (3):
\[
x^3 + 5x^2 + 8x + 4
\]
\(P(x) = x^3 + 5x^2 + 8x + 4\)에서 \(P(-1) = -1 + 5 - 8 + 4 = 0\)이므로
\[
= (x + 1)(x^2 + 4x + 4) = (x + 1)(x + 2)^2
\]
밑면이 정사각형이므로 밑면의 한 변의 길이는 \(x + 2\), 높이는 \(x + 1\).

### 4번 (문제해결)

**지문**: 다항식 \(x^4 - 15x^2 + ax + b\)는 \(x - 2\)로 나누어떨어지고, \(x + 2\)로 나누었을 때의 나머지가 \(-40\)이다. 상수 \(a\), \(b\)의 값을 구하고, 이 다항식을 인수분해하시오.

**풀이**:

\(P(x) = x^4 - 15x^2 + ax + b\)로 놓으면

\(P(2) = 16 - 60 + 2a + b = 0\) \(\Rightarrow 2a + b = 44\) ... (i)

\(P(-2) = 16 - 60 - 2a + b = -40\) \(\Rightarrow -2a + b = 4\) ... (ii)

(i), (ii)를 연립하면: \(a = 10\), \(b = 24\)

\(P(x) = x^4 - 15x^2 + 10x + 24\)

\(P(2) = 0\)이므로 조립제법으로 \(P(x) = (x - 2)(x^3 + 2x^2 - 11x - 12)\)

\(Q(x) = x^3 + 2x^2 - 11x - 12\)에서 \(Q(-1) = -1 + 2 + 11 - 12 = 0\)이므로

\(Q(x) = (x + 1)(x^2 + x - 12) = (x + 1)(x + 4)(x - 3)\)

\(\therefore P(x) = (x - 2)(x + 1)(x + 4)(x - 3)\)

**정답**: \(a = 10\), \(b = 24\), \(P(x) = (x - 2)(x + 1)(x + 4)(x - 3)\)

### 5번 (문제해결)

**지문**: 다항식 \(P(x) = x^3 + 2x^2 - 7x + 4\)에 대하여 \(P(11)\)의 값을 구하시오.

**풀이**:

조립제법을 이용하여 \(P(x)\)를 \(x - 11\)로 나눈 나머지를 구한다.

\(P(11) = 11^3 + 2 \times 11^2 - 7 \times 11 + 4 = 1331 + 242 - 77 + 4 = 1500\)

**정답**: \(1500\)

## 지도 TIP

- 인수분해 공식을 이용할 수 없거나 공통부분이 없는 **삼차, 사차 다항식의 인수분해**는 인수정리를 이용하도록 지도한다.
- 공통부분을 인수분해한 경우 그 결과는 **원래의 문자로 바꿔 나타내야** 함을 알게 한다.
- 각 블록의 부피와 개수를 이용하여 큰 직육면체의 부피를 \(x\)에 대한 식으로 나타내고, **인수분해를 이용하여 높이를 구할 수 있음**을 알게 한다.
