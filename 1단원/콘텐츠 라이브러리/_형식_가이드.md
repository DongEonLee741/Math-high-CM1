# 콘텐츠 라이브러리 형식 가이드

## 목적

이 라이브러리는 인터랙티브 학습지 제작 파이프라인(Phase 1)의 **Tier 1 주요 입력**이다.
학습지 제작 시 지도서 PDF 대신 이 라이브러리를 1차 소스로 사용하여 콘텐츠 오류율을 최소화한다.

## 파일 명명 규칙

```
{n}차시_{주제_키워드}.md
```

예: `3차시_다항식의곱셈_곱셈공식.md`

## 수식 표기 규칙

| 표기 | KaTeX |
|:---|:---|
| 거듭제곱 | `x^2`, `x^3`, `(a+b)^2` |
| 분수 | `\frac{a}{b}` |
| 색상 | `\textcolor{#E74C3C}{content}` |
| 인라인 | `\( ... \)` |
| 디스플레이 | `\[ ... \]` |
| 곱셈 점 | `\cdot` |
| 나눗셈 | `\div` |
| 플러스마이너스 | `\pm` |
| 따라서 | `\therefore` |
| 볼드 | `\boldsymbol{x}` |

## 정답 표기 원칙

1. **모든 정답은 KaTeX 포맷**으로 표기한다
2. 중간 풀이 과정도 가능한 한 포함한다
3. `<!-- VERIFY: 계산 검증 필요 -->` 플래그로 LLM 계산 결과를 표시한다
4. 지도서 정답과 대조 완료 시 플래그를 제거한다

## 인터랙티브 요소 매핑 기준

| 교과서 시각 자료 유형 | 권장 요소 |
|:---|:---|
| 화살표 전개 과정 | StepSimulation |
| 넓이 모델 / 기하 분할 | SVG Diagram + AlgebraTiles |
| 성질 / 정리 요약 (앞뒤) | FlipCard Single |
| 공식 5개+ 목록 | FormulaFlip Grid |
| TIP / 참고 정보 | Reference Box |
