## 탐구 열기

> 다음 등식 중에서 항등식인 것을 찾아보자.
>
> ㄱ. \(x^2 - 3x = 0\)
> ㄴ. \(x^2 - 3x = x(x-3)\)

**정답**:
- ㄱ. 등식 ㄱ을 만족시키는 \(x\)의 값은 \(0\), \(3\)뿐이므로 항등식이 아니다.
- ㄴ. \(x^2 - 3x = x(x-3)\)은 \(x\)에 어떤 값을 대입해도 항상 성립하므로 \(x\)에 대한 항등식이다.

---

## 핵심 개념

### 항등식의 성질

등식 \(ax^2 + bx + c = 0\)이 \(x\)에 대한 항등식이 되기 위한 조건:

\(x\)에 어떤 값을 대입해도 항상 성립하므로

\(x = 0\)을 대입하면 \(c = 0\)

즉 \(ax^2 + bx = 0\)이므로 이 식에

\(x = 1\)을 대입하면 \(a + b = 0\) ... ㉠

\(x = -1\)을 대입하면 \(a - b = 0\) ... ㉡

㉠, ㉡을 연립하여 풀면 \(a = 0\), \(b = 0\)이다.

일반적으로 항등식의 성질은 다음과 같다.

> **항등식의 성질**
>
> **❶** \(ax^2 + bx + c = 0\)이 \(x\)에 대한 항등식이면 \(a = 0\), \(b = 0\), \(c = 0\)이다.
>
> 또 \(a = 0\), \(b = 0\), \(c = 0\)이면 \(ax^2 + bx + c = 0\)은 \(x\)에 대한 항등식이다.
>
> **❷** \(ax^2 + bx + c = a'x^2 + b'x + c'\)이 \(x\)에 대한 항등식이면 \(a = a'\), \(b = b'\), \(c = c'\)이다.
>
> 또 \(a = a'\), \(b = b'\), \(c = c'\)이면 \(ax^2 + bx + c = a'x^2 + b'x + c'\)은 \(x\)에 대한 항등식이다.

### 미정계수법

항등식의 성질을 이용하여 주어진 등식에서 미지의 계수와 상수항을 정하는 방법을 **미정계수법**이라 한다.

미정계수법에는 다음 두 가지 방법이 있다.

- **방법 1 (계수비교법)**: 양변의 동류항의 계수를 비교하여 계수를 정하는 방법
- **방법 2 (수치대입법)**: 문자에 적당한 수를 대입하여 계수를 정하는 방법

## 예제

### 예제: 항등식의 성질을 이용하여 미정계수 구하기

**지문**: 다음 등식이 \(x\)에 대한 항등식이 되게 하는 상수 \(a\), \(b\), \(c\)의 값을 구하시오.
\[
a(x-1)^2 + b(x-1) + c = x^2 + 2x + 3
\]

**풀이 (방법 1: 양변의 동류항의 계수 비교하기)**:

좌변을 전개하여 정리하면
\[
a(x^2 - 2x + 1) + b(x - 1) + c = x^2 + 2x + 3
\]
\[
ax^2 - 2ax + a + bx - b + c = x^2 + 2x + 3
\]
\[
ax^2 + (b - 2a)x + (a - b + c) = x^2 + 2x + 3
\]

항등식의 성질을 이용하여 양변의 동류항의 계수를 비교하면

\(a = 1\) ... ㉠

\(b - 2a = 2\) ... ㉡

\(a - b + c = 3\) ... ㉢

㉠, ㉡, ㉢을 연립하여 풀면

**답**: \(a = 1\), \(b = 4\), \(c = 6\)

**풀이 (방법 2: \(x\)에 적당한 수 대입하기)**:

양변에 \(x = 1\)을 대입하면

\(c = 1 + 2 + 3 = 6\) ... ㉠

양변에 \(x = 0\)을 대입하면

\(a - b + c = 3\), 즉 \(a - b = -3\) ... ㉡

양변에 \(x = 2\)를 대입하면

\(a + b + c = 4 + 4 + 3 = 11\), 즉 \(a + b = 5\) ... ㉢

㉠, ㉡, ㉢을 연립하여 풀면

**답**: \(a = 1\), \(b = 4\), \(c = 6\)

## 문제

### 문제 1

**지문**: 다음 등식이 \(x\)에 대한 항등식이 되게 하는 상수 \(a\), \(b\), \(c\)의 값을 구하시오.
⑴ \((a-2)x^2 + (b+3)x + c - 1 = 0\)
⑵ \(x^2 + ax + 4 = bx^2 + 6x - c\)

**정답**:
- ⑴ 항등식의 성질 ❶에 의하여 \(a - 2 = 0\), \(b + 3 = 0\), \(c - 1 = 0\)이므로 \(a = 2\), \(b = -3\), \(c = 1\)
- ⑵ 항등식의 성질 ❷에 의하여 \(1 = b\), \(a = 6\), \(4 = -c\)이므로 \(a = 6\), \(b = 1\), \(c = -4\)

### 문제 2

**지문**: 다음 등식이 \(x\)에 대한 항등식이 되게 하는 상수 \(a\), \(b\), \(c\)의 값을 구하시오.
⑴ \(2x^3 - 6x + 4 = a(x-1)^3 + b(x-1)^2 + c\)
⑵ \(x^3 + ax + 4 = (x+1)(x^2 + bx + c)\)

**정답**:
- ⑴ \(a = 2\), \(b = 6\), \(c = 0\) <!-- VERIFY: 계산 검증 필요 -->
- ⑵ \(a = 3\), \(b = -1\), \(c = 4\) <!-- VERIFY: 계산 검증 필요 -->

## 지도 TIP

- 등식의 종류에는 항등식과 방정식이 있음을 설명하고 그 차이를 알게 한다.
- 항등식에 임의의 값을 대입해도 그 등식이 성립함을 설명한다.
- 미정계수법은 두 가지 방법이 있음을 설명하고 각각의 사용법을 알게 한다.
- 항등식의 미정계수를 정하는 방법은 두 가지가 있음을 상기시킨다.
