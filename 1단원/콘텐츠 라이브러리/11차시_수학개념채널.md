# 11차시: 수학+개념 채널 - 최고차항의 계수가 1이 아닌 다항식의 인수 찾기

## 메타데이터
- **단원**: 수학+개념 채널
- **교과서**: 33쪽
- **지도서**: 63쪽
- **성취기준**: 다항식의 인수분해를 할 수 있다.

---

## 핵심 개념

### 최고차항의 계수가 1이 아닌 다항식의 인수 찾기

최고차항의 계수가 1이 아니고 계수가 정수인 다항식 \(P(x)\)의 인수는 다음과 같이 찾는다.

\(P(a) = 0\)이 되게 하는 유리수 \(a\)를

\[
\pm \frac{\text{(상수항의 약수)}}{\text{(최고차항의 계수의 약수)}}
\]

중에서 찾는다. 이때 \(P(a) = 0\)이므로 다항식 \(P(x)\)는 \(x - a\)를 인수로 갖는다.

---

## 역량 키우기 (문제해결)

### 예시: \(P(x) = 2x^3 + 3x^2 - 4x + 1\)의 인수분해

**1단계**: 다항식 \(P(x)\)가 계수가 정수인 두 다항식의 곱으로 인수분해된다고 가정하자.

\[
P(x) = 2x^3 + 3x^2 - 4x + 1 = (ax + b)(px^2 + qx + r)
\]
\[
= apx^3 + (aq + bp)x^2 + (ar + bq)x + br \quad \text{(단, } a, b, p, q, r \text{는 정수)}
\]

**2단계**: 가능한 \(-\dfrac{b}{a}\)의 값을 구해 보자.

\(ap = 2\), \(br = 1\)에서 \(a\), \(b\)는 정수이므로:
- \(a\)는 \(\pm 1, \pm 2\) 중에서 하나
- \(b\)는 \(\pm 1\) 중에서 하나

따라서 가능한 \(-\dfrac{b}{a}\)의 값은 \(\pm 1\) 또는 \(\pm \dfrac{1}{2}\)이다.

**3단계**: \(P(x)\)의 인수를 찾아 \(P(x)\)를 인수분해해 보자.

\[
P\!\left(\frac{1}{2}\right) = 2 \cdot \frac{1}{8} + 3 \cdot \frac{1}{4} - 4 \cdot \frac{1}{2} + 1 = \frac{1}{4} + \frac{3}{4} - 2 + 1 = 0
\]

\(P\!\left(\dfrac{1}{2}\right) = 0\)이므로 다항식 \(P(x)\)는 \(x - \dfrac{1}{2}\)을 인수로 갖는다.

조립제법으로 \(P(x)\)를 인수분해하면:

| | 2 | 3 | \(-4\) | 1 |
|---|---|---|---|---|
| \(\frac{1}{2}\) | | 1 | 2 | \(-1\) |
| | 2 | 4 | \(-2\) | 0 |

\[
2x^3 + 3x^2 - 4x + 1 = \left(x - \frac{1}{2}\right)(2x^2 + 4x - 2) = (2x - 1)(x^2 + 2x - 1)
\]

**답**: \((2x - 1)(x^2 + 2x - 1)\)

---

### 탐구 과제: \(P(x) = 3x^3 - 7x^2 + 11x - 3\)

**지문**: 다항식 \(P(x) = 3x^3 - 7x^2 + 11x - 3\)의 인수를 찾고, \(P(x)\)를 인수분해해 보자.

**풀이**:

\(P(a) = 0\)이 되게 하는 유리수 \(a\)를 \(\pm \dfrac{\text{(상수항의 약수)}}{\text{(최고차항의 계수의 약수)}}\) 중에서 찾는다.

- 상수항의 약수: \(\pm 1, \pm 3\)
- 최고차항의 계수의 약수: \(\pm 1, \pm 3\)

가능한 후보: \(\pm 1, \pm 3, \pm \dfrac{1}{3}\)

\[
P\!\left(\frac{1}{3}\right) = 3 \cdot \frac{1}{27} - 7 \cdot \frac{1}{9} + 11 \cdot \frac{1}{3} - 3 = \frac{1}{9} - \frac{7}{9} + \frac{11}{3} - 3 = \frac{1 - 7 + 33 - 27}{9} = 0
\]

\(P\!\left(\dfrac{1}{3}\right) = 0\)이므로 \(P(x)\)는 \(x - \dfrac{1}{3}\)을 인수로 갖는다.

조립제법:

| | 3 | \(-7\) | 11 | \(-3\) |
|---|---|---|---|---|
| \(\frac{1}{3}\) | | 1 | \(-2\) | 3 |
| | 3 | \(-6\) | 9 | 0 |

\[
3x^3 - 7x^2 + 11x - 3 = \left(x - \frac{1}{3}\right)(3x^2 - 6x + 9) = (3x - 1)(x^2 - 2x + 3)
\]

**답**: \((3x - 1)(x^2 - 2x + 3)\)

---

## 지도 TIP

- 최고차항의 계수가 **1인 경우**는 상수항의 약수만 대입하면 되지만 (교과서 31쪽), 최고차항의 계수가 **1이 아닌 경우**는 \(\pm \dfrac{\text{(상수항의 약수)}}{\text{(최고차항의 계수의 약수)}}\)를 이용하도록 지도한다.
- 조립제법의 결과에서 \(\left(x - \dfrac{b}{a}\right)\)와 몫 다항식의 곱으로 나타낸 뒤, **정수 계수로 정리**하는 과정을 강조한다.
