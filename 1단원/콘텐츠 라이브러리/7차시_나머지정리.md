## 탐구 열기

> 다항식 \(P(x) = x^2 + 3x - 6\)에 대하여 물음에 답해 보자.
>
> ⑴ \(P(x)\)를 \(x - 2\)로 나누었을 때의 나머지를 구하시오.
> ⑵ \(P(2)\)를 구하고, ⑴에서 구한 나머지와 비교하시오.

**정답**:
- ⑴ \(x^2 + 3x - 6 = (x - 2)(x + 5) + 4\)이므로 나머지는 \(4\)
- ⑵ \(P(2) = 4 + 6 - 6 = 4\), ⑴에서 구한 나머지와 같다.

---

## 핵심 개념

### 나머지정리

다항식을 일차식으로 직접 나누지 않고도 나머지를 구할 수 있는 방법이다.

다항식 \(P(x)\)를 일차식 \(x - a\)로 나누었을 때의 몫을 \(Q(x)\), 나머지를 \(R\)라 하면

\[
P(x) = (x - a)Q(x) + R \quad (R\text{는 상수})
\]

이므로 이 항등식의 양변에 \(x = a\)를 대입하면 \(P(a) = R\)이다.

> **나머지정리**
>
> 다항식 \(P(x)\)를 일차식 \(x - a\)로 나누었을 때의 나머지는
> \[
> R = P(a)
> \]

참고: 다항식을 일차식으로 나눌 때
- ❶ 몫과 나머지를 모두 구할 때 → **조립제법** 이용
- ❷ 나머지만 구할 때 → **나머지정리** 이용

### 일차식 ax+b로 나누었을 때의 나머지

다항식 \(P(x)\)를 일차식 \(ax + b\)로 나누었을 때의 나머지는

\[
R = P\!\left(-\frac{b}{a}\right)
\]

---

## 예제

### 예제: 다항식을 ax+b로 나누었을 때의 나머지 구하기

**지문**: 다항식 \(P(x) = 2x^3 - 3x^2 + 4\)를 \(2x + 1\)로 나누었을 때의 나머지를 구하시오.

**풀이**:

\(P(x)\)를 \(2x + 1\)로 나누었을 때의 몫을 \(Q(x)\), 나머지를 \(R\)라 하면

\[
P(x) = (2x + 1)Q(x) + R
\]

이 등식은 \(x\)에 대한 항등식이므로 양변에 \(x = -\dfrac{1}{2}\)을 대입하면

\[
P\!\left(-\frac{1}{2}\right) = 0 \cdot Q\!\left(-\frac{1}{2}\right) + R = R
\]

따라서 구하는 나머지 \(R\)는

\[
R = P\!\left(-\frac{1}{2}\right) = 2 \cdot \left(-\frac{1}{2}\right)^3 - 3 \cdot \left(-\frac{1}{2}\right)^2 + 4 = -\frac{1}{4} - \frac{3}{4} + 4 = 3
\]

**답**: \(3\)

### 예제: 다항식을 이차식으로 나누었을 때의 나머지 구하기

**지문**: 다항식 \(P(x)\)를 \(x - 1\)로 나누었을 때의 나머지가 \(5\)이고, \(x + 2\)로 나누었을 때의 나머지가 \(-4\)이다. \(P(x)\)를 \((x - 1)(x + 2)\)로 나누었을 때의 나머지를 구하시오.

**풀이**:

\(P(x)\)를 \((x - 1)(x + 2)\)로 나누었을 때의 몫을 \(Q(x)\), 나머지를 \(ax + b\) (\(a\), \(b\)는 상수)라 하면

\[
P(x) = (x - 1)(x + 2)Q(x) + ax + b
\]

\(P(x)\)를 \(x - 1\)로 나누었을 때의 나머지가 \(5\)이므로

\(P(1) = 5\), 즉 \(a + b = 5\) ... ㉠

\(P(x)\)를 \(x + 2\)로 나누었을 때의 나머지가 \(-4\)이므로

\(P(-2) = -4\), 즉 \(-2a + b = -4\) ... ㉡

㉠, ㉡을 연립하여 풀면

\(a = 3\), \(b = 2\)

따라서 구하는 나머지는 \(3x + 2\)

**답**: \(3x + 2\)

## 문제

### 문제 3

**지문**: 다항식 \(P(x) = x^3 + 4x^2 + x - 5\)를 다음 일차식으로 나누었을 때의 나머지를 구하시오.
⑴ \(x - 1\)
⑵ \(x + 2\)
⑶ \(x - \dfrac{1}{2}\)

**정답**:
- ⑴ \(P(1) = 1 + 4 + 1 - 5 = 1\)
- ⑵ \(P(-2) = -8 + 16 - 2 - 5 = 1\)
- ⑶ \(P\!\left(\dfrac{1}{2}\right) = \dfrac{1}{8} + 1 + \dfrac{1}{2} - 5 = -\dfrac{27}{8}\) <!-- VERIFY: 계산 검증 필요 -->

### 문제 4

**지문**: 다항식 \(P(x) = 6x^3 - x + 1\)을 다음 일차식으로 나누었을 때의 나머지를 구하시오.
⑴ \(2x - 1\)
⑵ \(3x + 2\)

**정답**:
- ⑴ \(P\!\left(\dfrac{1}{2}\right) = 6 \cdot \dfrac{1}{8} - \dfrac{1}{2} + 1 = \dfrac{3}{4} - \dfrac{1}{2} + 1 = \dfrac{5}{4}\)
- ⑵ \(P\!\left(-\dfrac{2}{3}\right) = 6 \cdot \left(-\dfrac{8}{27}\right) + \dfrac{2}{3} + 1 = -\dfrac{16}{9} + \dfrac{2}{3} + 1 = -\dfrac{1}{9}\) <!-- VERIFY: 계산 검증 필요 -->

### 문제 5

**지문**: 다항식 \(P(x)\)를 \(x + 3\)으로 나누었을 때의 나머지가 \(-1\)이고, \(x - 2\)로 나누었을 때의 나머지가 \(4\)이다. \(P(x)\)를 \((x + 3)(x - 2)\)로 나누었을 때의 나머지를 구하시오.

**정답**:

\(P(x) = (x + 3)(x - 2)Q(x) + ax + b\)로 놓으면

\(P(-3) = -1\)에서 \(-3a + b = -1\) ... ㉠

\(P(2) = 4\)에서 \(2a + b = 4\) ... ㉡

㉠, ㉡을 연립하여 풀면 \(a = 1\), \(b = 2\)

따라서 나머지는 \(x + 2\)

## 지도 TIP

- ⑴을 설명하고 등식 \(x^2 + 3x - 6 = (x - 2)(x + 5) + 4\)는 항등식임을 알게 한다.
- 항등식의 성질을 이용하여 ⑵에서 값이 같은 이유를 알게 한다.
- 다항식을 일차식으로 나눈 나머지를 구할 때, 나머지정리를 사용할 수 있음을 알게 한다.
- 다항식 \(P(x)\)를 이차식으로 나눈 나머지는 일차식 \(ax + b\)로 나타냄을 알게 한다.
