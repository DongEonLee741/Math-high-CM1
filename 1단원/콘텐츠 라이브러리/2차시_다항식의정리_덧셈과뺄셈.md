## 탐구 열기

> **다항식은 어떻게 정리할까?**
>
> 다음 두 다항식의 차수를 구하고, 차수를 구하기 편리한 것은 어느 것인지 말해 보자.
>
> - ⑴ \(3x^2 + 1 + 4x^3 + x^5 + 4x + 2x^4\)
> - ⑵ \(x^5 + 2x^4 + 4x^3 + 3x^2 + 4x + 1\)

**정답**:
- 두 다항식 모두 차수는 \(5\)이다.
- ⑵가 차수를 구하기 편리하다. (내림차순으로 정리되어 있으므로)

> **단백질 함유량 예시** (교과서 시각 자료)
>
> 닭가슴살 1팩(100 g)당 단백질 23 g, 연어 23.8 g, 오징어 18.2 g.
> 닭가슴살 1팩, 연어 \(x^2\)팩, 오징어 \(x\)팩을 먹으면 단백질의 양을 식으로 나타내면 \(x\)에 대한 이차식이 된다.

## 핵심 개념

### 다항식의 정리

다항식의 항을 차수의 크기순으로 정리하면 식의 계산이 편리하다.

- **내림차순으로 정리한다**: 다항식을 한 문자에 대하여 차수가 높은 항부터 낮은 항의 순서로 나타내는 것
- **오름차순으로 정리한다**: 다항식을 한 문자에 대하여 차수가 낮은 항부터 높은 항의 순서로 나타내는 것

> 다항식에서 상수항의 차수는 \(0\)으로 생각한다.

### 다항식의 덧셈과 뺄셈

다항식의 덧셈은 **동류항끼리 모아서 정리**한다.

다항식의 뺄셈은 **빼는 식의 각 항의 부호를 바꾸어서 더한다**. 즉 두 다항식 \(A\), \(B\)에 대하여

\[
A - B = A + (-B)
\]

### 다항식의 덧셈에 대한 성질

다항식의 덧셈에서는 수의 덧셈에서와 같이 다음 성질이 성립한다.

세 다항식 \(A\), \(B\), \(C\)에 대하여:
- ❶ 교환법칙: \(A + B = B + A\)
- ❷ 결합법칙: \((A + B) + C = A + (B + C)\)

> 덧셈에 대한 결합법칙이 성립하므로 \((A+B)+C\), \(A+(B+C)\)를 괄호를 생략하여 \(A+B+C\)로 나타내기도 한다.

## 문제

### 문제 1

**지문**: 다음 다항식을 \(x\)에 대하여 내림차순으로 정리하시오.

⑴ \(2x^2 + 3x + 1 + x^3\)

⑵ \(xy + 5x + 2y^3 - x^2 y - 2y + 1\)

**풀이**:

⑴
\[
2x^2 + 3x + 1 + x^3 = x^3 + 2x^2 + 3x + 1
\]

⑵ \(x\)에 대하여 정리하면 (\(y\)는 상수로 취급):
\[
xy + 5x + 2y^3 - x^2 y - 2y + 1 = -yx^2 + (y + 5)x + 2y^3 - 2y + 1
\]

**정답**:
- ⑴ \(x^3 + 2x^2 + 3x + 1\)
- ⑵ \(-yx^2 + (y + 5)x + 2y^3 - 2y + 1\)

---

## 예제

### 예제 1: 다항식의 덧셈과 뺄셈하기

**지문**: 두 다항식 \(A\), \(B\)가
\[
A = x^3 - 2x^2 + 1, \quad B = -2x^3 - 3x + 5
\]
일 때, 다음을 계산하시오.

⑴ \(A + B\)

⑵ \(A - B\)

**풀이**:

⑴ 동류항끼리 모아서 정리하면
\[
A + B = (x^3 - 2x^2 + 1) + (-2x^3 - 3x + 5)
\]
\[
= (1-2)x^3 - 2x^2 - 3x + (1+5)
\]
\[
= -x^3 - 2x^2 - 3x + 6
\]

⑵ 빼는 식의 각 항의 부호를 바꾸어서 더하면
\[
A - B = (x^3 - 2x^2 + 1) - (-2x^3 - 3x + 5)
\]
\[
= (x^3 - 2x^2 + 1) + (2x^3 + 3x - 5)
\]
\[
= (1+2)x^3 - 2x^2 + 3x + (1-5)
\]
\[
= 3x^3 - 2x^2 + 3x - 4
\]

**답**:
- ⑴ \(-x^3 - 2x^2 - 3x + 6\)
- ⑵ \(3x^3 - 2x^2 + 3x - 4\)

### 예제 2: 다항식의 덧셈에 대한 성질 이해하기

**지문**: 두 다항식 \(A\), \(B\)가
\[
A = x^3 + x^2 + 1, \quad B = 3x^3 - x^2 + 2x + 4
\]
일 때, \((2A + 3B) + (A - 4B)\)를 계산하시오.

**풀이**:
\[
(2A + 3B) + (A - 4B) = 2A + 3B + A - 4B
\]
\[
= 2A + A + 3B - 4B \quad \text{(교환법칙)}
\]
\[
= (2A + A) + (3B - 4B) \quad \text{(결합법칙)}
\]
\[
= 3A - B
\]
\[
= 3(x^3 + x^2 + 1) - (3x^3 - x^2 + 2x + 4)
\]
\[
= (3x^3 + 3x^2 + 3) + (-3x^3 + x^2 - 2x - 4)
\]
\[
= (3 - 3)x^3 + (3 + 1)x^2 - 2x + (3 - 4)
\]
\[
= 4x^2 - 2x - 1
\]

**답**: \(4x^2 - 2x - 1\)

## 문제 (계속)

### 문제 2

**지문**: 두 다항식 \(A\), \(B\)가
\[
A = 2x^2 - 4x - 3, \quad B = 3x^3 + x - 2
\]
일 때, 다음을 계산하시오.

⑴ \(A + B\)

⑵ \(A - B\)

**풀이**:

⑴
\[
A + B = (2x^2 - 4x - 3) + (3x^3 + x - 2)
\]
\[
= 3x^3 + 2x^2 + (-4 + 1)x + (-3 - 2)
\]
\[
= 3x^3 + 2x^2 - 3x - 5
\]

⑵
\[
A - B = (2x^2 - 4x - 3) - (3x^3 + x - 2)
\]
\[
= (2x^2 - 4x - 3) + (-3x^3 - x + 2)
\]
\[
= -3x^3 + 2x^2 + (-4 - 1)x + (-3 + 2)
\]
\[
= -3x^3 + 2x^2 - 5x - 1
\]

**정답**:
- ⑴ \(3x^3 + 2x^2 - 3x - 5\)
- ⑵ \(-3x^3 + 2x^2 - 5x - 1\)

### 스스로 하기

**지문**: 두 다항식 \(A\), \(B\)가
\[
A = x^3 + 3x^2 - 2x + 1, \quad B = 2x^3 + 5x
\]
일 때, \(A + B\)와 \(A - B\)를 계산하시오.

**풀이**:

⑴
\[
A + B = (x^3 + 3x^2 - 2x + 1) + (2x^3 + 5x) = 3x^3 + 3x^2 + 3x + 1
\]

⑵
\[
A - B = (x^3 + 3x^2 - 2x + 1) - (2x^3 + 5x) = -x^3 + 3x^2 - 7x + 1
\]

**답**:
- \(A + B = 3x^3 + 3x^2 + 3x + 1\)
- \(A - B = -x^3 + 3x^2 - 7x + 1\)

### 문제 2 (두 변수)

**지문**: 두 다항식 \(A\), \(B\)가
\[
A = 2x^2 - xy + 2y^2, \quad B = x^2 - 3xy - 2y^2
\]
일 때, \(A + B\)와 \(A - B\)를 계산하시오.

**풀이**:

⑴
\[
A + B = (2x^2 - xy + 2y^2) + (x^2 - 3xy - 2y^2)
\]
\[
= (2 + 1)x^2 + (-1 - 3)xy + (2 - 2)y^2
\]
\[
= 3x^2 - 4xy
\]

⑵
\[
A - B = (2x^2 - xy + 2y^2) - (x^2 - 3xy - 2y^2)
\]
\[
= (2 - 1)x^2 + (-1 + 3)xy + (2 + 2)y^2
\]
\[
= x^2 + 2xy + 4y^2
\]

**정답**:
- \(A + B = 3x^2 - 4xy\)
- \(A - B = x^2 + 2xy + 4y^2\)

### 문제 3

**지문**: 세 다항식 \(A\), \(B\), \(C\)가
\[
A = x^3 - x^2 + 2, \quad B = x^3 + 2x^2, \quad C = -x^3 + 3x + 2
\]
일 때, 다음을 계산하시오.

⑴ \((A - 2B) + (3A + B)\)

⑵ \((A - 2B) - (3B - 2C)\)

**풀이**:

⑴ 먼저 식을 정리한 후에 다항식을 대입한다.
\[
(A - 2B) + (3A + B) = A - 2B + 3A + B = 4A - B
\]
\[
= 4(x^3 - x^2 + 2) - (x^3 + 2x^2)
\]
\[
= (4x^3 - 4x^2 + 8) + (-x^3 - 2x^2)
\]
\[
= 3x^3 - 6x^2 + 8
\]

⑵
\[
(A - 2B) - (3B - 2C) = A - 2B - 3B + 2C = A - 5B + 2C
\]
\[
= (x^3 - x^2 + 2) - 5(x^3 + 2x^2) + 2(-x^3 + 3x + 2)
\]
\[
= (x^3 - x^2 + 2) + (-5x^3 - 10x^2) + (-2x^3 + 6x + 4)
\]
\[
= (1 - 5 - 2)x^3 + (-1 - 10)x^2 + 6x + (2 + 4)
\]
\[
= -6x^3 - 11x^2 + 6x + 6
\]

**정답**:
- ⑴ \(3x^3 - 6x^2 + 8\)
- ⑵ \(-6x^3 - 11x^2 + 6x + 6\)

### 문제 4

**지문**: 두 다항식 \(A\), \(B\)가
\[
A = x^2 + 2y^2, \quad B = 4x^2 - y
\]
일 때, 다음 등식을 만족시키는 다항식 \(X\)를 구하시오.

⑴ \(A + X = B\)

⑵ \(3X - 2A = B + 2X\)

**풀이**:

⑴
\[
X = B - A = (4x^2 - y) - (x^2 + 2y^2)
\]
\[
= 4x^2 - y - x^2 - 2y^2
\]
\[
= 3x^2 - 2y^2 - y
\]

⑵
\[
3X - 2A = B + 2X
\]
\[
3X - 2X = B + 2A
\]
\[
X = B + 2A = (4x^2 - y) + 2(x^2 + 2y^2)
\]
\[
= 4x^2 - y + 2x^2 + 4y^2
\]
\[
= 6x^2 + 4y^2 - y
\]

**정답**:
- ⑴ \(3x^2 - 2y^2 - y\)
- ⑵ \(6x^2 + 4y^2 - y\)

## 지도 TIP

- 특정한 문자에 대하여 정리하는 경우, 나머지 문자는 모두 상수로 생각하여 정리하도록 지도한다.
- 보통 다항식을 정리할 때는 내림차순으로 정리하는 것이 일반적이라는 것을 알게 한다.
- 항을 불규칙하게 나열한 다항식과 내림차순으로 정리한 다항식의 차수를 각각 구해 보게 함으로써 다항식의 각 항을 차수에 따라 순서대로 나타내면 편리하다는 것을 알게 한다.
- 다항식의 덧셈과 뺄셈을 할 때, 문자와 차수가 같은 항, 즉 동류항끼리 계산함에 유의하도록 지도한다.
- 다항식의 덧셈에서 교환법칙과 결합법칙이 성립함을 간단한 예를 들어 직관적으로 이해하게 한다.
  - 교환법칙 예시: \(x + 3x = 3x + x\)
  - 결합법칙 예시: \((x + 2x) + 3x = x + (2x + 3x)\)
- 영양소 계산뿐만 아니라 건축물의 설계, 전기나 가스 요금의 계산 등 우리 생활에서 관찰할 수 있는 다양한 현상을 다항식으로 나타낼 수 있도록 지도한다.
