## 핵심 개념

### 인수정리

다항식 \(P(x)\)를 일차식 \(x - a\)로 나누었을 때의 나머지는 \(P(a)\)이다. 이때

\(P(a) = 0\)이면 \(P(x)\)는 \(x - a\)로 나누어떨어진다. 즉 \(x - a\)는 \(P(x)\)의 인수이다.

거꾸로 \(x - a\)가 \(P(x)\)의 인수이면, 즉 \(P(x)\)가 \(x - a\)로 나누어떨어지면

\[
P(x) = (x - a)Q(x)
\]

이므로 \(P(a) = 0\)임을 알 수 있다.

> **인수정리**
>
> 다항식 \(P(x)\)에 대하여
>
> **❶** \(P(a) = 0\)이면 \(P(x)\)는 일차식 \(x - a\)로 나누어떨어진다.
>
> **❷** \(P(x)\)가 일차식 \(x - a\)로 나누어떨어지면 \(P(a) = 0\)이다.

---

## 예제

### 예제: 인수정리를 이용하여 계수 구하기

**지문**: 다항식 \(P(x) = x^3 - ax + 4\)가 \(x - 2\)로 나누어떨어지게 하는 상수 \(a\)의 값을 구하시오.

**풀이**:

\(P(x)\)가 \(x - 2\)로 나누어떨어지면 인수정리에 의하여 \(P(2) = 0\)

\[
P(2) = 8 - 2a + 4 = -2a + 12
\]

이므로 \(-2a + 12 = 0\), 즉 \(a = 6\)

**답**: \(6\)

## 문제

### 문제 6

**지문**: 일차식 \(x + 2\)가 다항식 \(P(x) = x^3 + 5x^2 + 2ax + a\)의 인수가 되도록 하는 상수 \(a\)의 값을 구하시오.

**정답**:

\(x + 2\)가 \(P(x)\)의 인수이면 인수정리에 의하여 \(P(-2) = 0\)

\(P(-2) = -8 + 20 - 4a + a = 12 - 3a = 0\)

\(a = 4\)

### 문제 7

**지문**: 다항식 \(P(x) = x^3 + ax^2 + bx - 2\)가 \((x - 1)(x - 2)\)로 나누어떨어지게 하는 상수 \(a\), \(b\)의 값을 구하시오.

**정답**:

\(P(x)\)가 \(x - 1\)로 나누어떨어지면 \(P(1) = 0\)

\(1 + a + b - 2 = 0\), 즉 \(a + b = 1\) ... ㉠

\(P(x)\)가 \(x - 2\)로 나누어떨어지면 \(P(2) = 0\)

\(8 + 4a + 2b - 2 = 0\), 즉 \(4a + 2b = -6\), \(2a + b = -3\) ... ㉡

㉠, ㉡을 연립하여 풀면 \(a = -4\), \(b = 5\)

## 스스로 하기

**지문**: 일차식 \(x - 1\)이 다항식 \(P(x) = x^3 - 3x^2 + ax + 7\)의 인수가 되도록 하는 상수 \(a\)의 값을 구하시오.

**풀이**:

\(x - 1\)이 \(P(x)\)의 인수가 되려면 인수정리에 의하여 \(P(1) = 0\)

\[
P(1) = 1 - 3 + a + 7 = a + 5
\]

이므로 \(a + 5 = 0\), 즉 \(a = -5\)

**답**: \(-5\)

## 스스로 확인하기 (2. 항등식과 나머지정리)

### 1번

**지문**: 다음 등식이 \(x\)에 대한 항등식이 되게 하는 상수 \(a\), \(b\), \(c\)의 값을 구하시오.
⑴ \(x^3 + ax^2 + bx + 3 = x(x^2 - 1) + c\)
⑵ \(ax(x - 1) + b(x - 1)(x + 1) + cx(x + 1) = x^2 - 2x + 3\)

**정답**:
- ⑴ 우변을 전개하면 \(x^3 - x + c\)이므로 양변의 계수를 비교하면 \(a = 0\), \(b = -1\), \(c = 3\)
- ⑵ 수치대입법을 이용한다.
  - \(x = 0\)을 대입하면 \(-b = 3\), 즉 \(b = -3\)
  - \(x = 1\)을 대입하면 \(2c = 2\), 즉 \(c = 1\)
  - \(x = -1\)을 대입하면 \(2a = 6\), 즉 \(a = 3\)
  - 따라서 \(a = 3\), \(b = -3\), \(c = 1\)

### 2번

**지문**: 다항식 \(P(x)\)를 \(x - 1\)로 나누었을 때의 나머지가 \(-1\)이고, \(x - 2\)로 나누었을 때의 나머지가 \(1\)이다. \(P(x)\)를 \(x^2 - 3x + 2\)로 나누었을 때의 나머지를 구하시오.

**정답**:

\(x^2 - 3x + 2 = (x - 1)(x - 2)\)이므로

\(P(x) = (x - 1)(x - 2)Q(x) + ax + b\)로 놓으면

\(P(1) = -1\)에서 \(a + b = -1\) ... ㉠

\(P(2) = 1\)에서 \(2a + b = 1\) ... ㉡

㉠, ㉡을 연립하여 풀면 \(a = 2\), \(b = -3\)

따라서 나머지는 \(2x - 3\)

### 3번

**지문**: 이차식 \((x - 1)^2\)이 다항식 \(x^3 - x^2 + ax + b\)의 인수일 때, 상수 \(a\), \(b\)의 값을 구하시오.

**정답**:

\(P(x) = x^3 - x^2 + ax + b\)라 하면 \((x - 1)^2\)이 인수이므로 \(P(x) = (x - 1)^2(x + k)\)로 놓을 수 있다.

\(x^3\)의 계수를 비교하면 \(k\)의 값을 구할 수 있다. 상수항을 비교하면 \(b = k\)

\((x - 1)^2(x + k) = x^3 + (k - 2)x^2 + (1 - 2k)x + k\)

\(k - 2 = -1\)에서 \(k = 1\)

따라서 \(a = 1 - 2(1) = -1\), \(b = 1\)

\(a = -1\), \(b = 1\) <!-- VERIFY: 계산 검증 필요 -->

### 4번

**지문**: 다항식 \(x^5 + x^4 + 3x\)를 \(x + 1\)로 나누었을 때의 몫을 \(Q(x)\)라 할 때, \(Q(x)\)를 \(x - 1\)로 나누었을 때의 나머지를 구하시오.

**정답**:

\(x^5 + x^4 + 3x = (x + 1)Q(x)\)이므로

\(Q(x) = \dfrac{x^5 + x^4 + 3x}{x + 1}\)

\(Q(1)\)을 구하면 되므로, \(x^5 + x^4 + 3x = (x + 1)Q(x)\)에서

\(x = 1\)을 대입하면 \(1 + 1 + 3 = 2 \cdot Q(1)\)

\(Q(1) = \dfrac{5}{2}\)

### 생각 넓히기 (5번)

**지문**: 다항식 \(f(x) = 2x^3 + ax^2 + bx + c\)가 다음 조건을 만족시킬 때, \(a + b + c\)의 값을 구하시오. (단, \(a\), \(b\), \(c\)는 상수)

조건:
- (가) \(2x + 1\)은 \(f(x)\)의 인수이다.
- (나) \(f(x)\)를 \(x^2 + x - 1\)로 나눈 나머지가 \(2x + 1\)이다.

**정답**:

조건 (나)에 의해 \(f(x) = (x^2 + x - 1)(2x + d) + 2x + 1\)

전개하면 \(f(x) = 2x^3 + (d + 2)x^2 + dx - d + 1\)

조건 (가)에 의해 \(f\!\left(-\dfrac{1}{2}\right) = 0\)이므로 \(d = 1\)

따라서 \(f(x) = 2x^3 + 3x^2 + x\)이므로

\(a + b + c = 3 + 1 + 0 = 4\)

### 생각 넓히기: \(x^3\)의 계수가 1인 삼차다항식

**지문**: \(x^3\)의 계수가 1인 삼차다항식 \(P(x)\)에 대하여 \(P(-1) = P(1) = P(2) = 3\)일 때, \(P(-2)\)의 값을 구해 보자.

**정답**:

\(P(x) - 3 = T(x)\)로 놓으면 \(T(x)\)는 \(x^3\)의 계수가 1인 삼차다항식이다.

\(P(-1) = P(1) = P(2) = 3\)이므로

\(T(-1) = T(1) = T(2) = 0\)

따라서 \(T(x) = (x + 1)(x - 1)(x - 2)\)

그러므로 \(P(-2) = T(-2) + 3 = (-1)(-3)(-4) + 3 = -12 + 3 = -9\)

## 지도 TIP

- 인수정리는 나머지정리의 특별한 경우임을 알게 한다.
- 인수정리를 이용하여 지도한다.
- \(T(-1) = T(1) = T(2) = 0\)임을 알 수 있도록 지도한다.
