### 01번

**지문**: 두 다항식 \(A\), \(B\)가 \(A = 3x^2 - xy + y^2\), \(B = x^2 + 2xy - 3y^2\)일 때, 등식 \(A - X = 2B\)를 만족시키는 다항식 \(X\)는?

| 보기 | |
|:---|:---|
| ① \(x^2 - 4xy + 6y^2\) | ② \(x^2 - 5xy + 6y^2\) |
| ③ \(x^2 - 4xy + 7y^2\) | ④ \(x^2 - 5xy + 7y^2\) |
| ⑤ \(2x^2 - 5xy + 7y^2\) | |

**풀이**:
\[
X = A - 2B = (3x^2 - xy + y^2) - 2(x^2 + 2xy - 3y^2)
\]
\[
= 3x^2 - xy + y^2 - 2x^2 - 4xy + 6y^2 = x^2 - 5xy + 7y^2
\]

**정답**: ④

### 02번

**지문**: 다음 그림과 같이 한 개의 직사각형을 6개의 직사각형으로 나누었을 때, 6개의 직사각형의 넓이가 각각 \(A\), \(5\), \(6\), \(4\), \(B\), \(C\)이다. 이때 \(A(B + C)\)의 값은?

| 보기 | |
|:---|:---|
| ① 41 | ② 42 |
| ③ 43 | ④ 44 |
| ⑤ 45 | |

**풀이**:

직사각형의 넓이 관계에서 가로, 세로 길이를 이용한다.

윗줄: \(A\), \(5\), \(6\) / 아랫줄: \(4\), \(B\), \(C\)

\(A : 4 = 5 : B = 6 : C\) (같은 행의 세로 비율)

\(\dfrac{A}{4} = \dfrac{5}{B} = \dfrac{6}{C}\)에서 \(AB = 20\), \(AC = 24\)

\(\therefore A(B + C) = AB + AC = 20 + 24 = 44\)

### 03번

**지문**: \(a + b + c = 1\), \(ab + bc + ca = -2\)일 때, \(a^2 + b^2 + c^2\)의 값은?

| 보기 | |
|:---|:---|
| ① 1 | ② 2 |
| ③ 3 | ④ 4 |
| ⑤ 5 | |

**풀이**:
\[
(a + b + c)^2 = a^2 + b^2 + c^2 + 2(ab + bc + ca)
\]
\[
1 = a^2 + b^2 + c^2 + 2 \times (-2) = a^2 + b^2 + c^2 - 4
\]
\[
a^2 + b^2 + c^2 = 5

### 05번

**지문**: 다항식 \(x^4 + 3x^2 + ax + 4\)가 \(x^2 + x + b\)로 나누어떨어질 때, \(a + b\)의 값은? (단, \(a\), \(b\)는 상수)

| 보기 | |
|:---|:---|
| ① 2 | ② 3 |
| ③ 4 | ④ 5 |
| ⑤ 6 | |

**풀이**:

\(x^4 + 3x^2 + ax + 4 = (x^2 + x + b)(x^2 + cx + d)\)로 놓자. (단, \(c\), \(d\)는 상수)

전개하면:
\[
x^4 + (c + 1)x^3 + (d + c + b)x^2 + (cd + bc)x + bd
\]

\(x^3\)의 계수: \(c + 1 = 0\) \(\Rightarrow c = -1\)

\(x^2\)의 계수: \(d + c + b = 3\) \(\Rightarrow d - 1 + b = 3\) \(\Rightarrow d + b = 4\)

상수항: \(bd = 4\)

\(x\)의 계수: \(cd + bc = a\) \(\Rightarrow -d + b(-1) = a\) \(\Rightarrow -(d + b) = a\) ... 이 아니라

\(cd + bc = c(d + b) = -1 \times 4 = -4\)이므로 \(a = -4\) ... 이 아니라

\(cd + bc = -d + b \times (-1) = -d - b\) ... 아, 다시 계산하면:

\(cd + bc = c \cdot d + b \cdot c = c(d + b) = -1 \times 4 = -4\)

따라서 \(a = -4\)

\(bd = 4\), \(d + b = 4\)에서 \(b\)와 \(d\)는 \(t^2 - 4t + 4 = 0\)의 근, 즉 \(b = d = 2\)

\(a + b = -4 + 2 = -2\)

이것은 보기에 없으므로 다시 계산한다. <!-- VERIFY: 계산 검증 필요 -->

\(x^4 + 3x^2 + ax + 4 = (x^2 + x + b)(x^2 - x + \frac{4}{b})\)

\(x^2\)의 계수: \(\frac{4}{b} - 1 + b = 3\), \(b + \frac{4}{b} = 4\), \(b^2 - 4b + 4 = 0\), \(b = 2\)

\(x\)의 계수: \(a = -\frac{4}{b} + b = -2 + 2 = 0\)

\(a + b = 0 + 2 = 2\)

**정답**: ① <!-- VERIFY: 계산 검증 필요 -->

### 06번

**지문**: 등식 \(3x^3 - x^2 + 4x + 1 = 3(x + 1)^3 + a(x + 1)^2 + b(x + 1) - 7\)이 \(x\)에 대한 항등식일 때, \(a + 2b\)의 값은? (단, \(a\), \(b\)는 상수)

| 보기 | |
|:---|:---|
| ① 16 | ② 20 |
| ③ 24 | ④ 28 |
| ⑤ 32 | |

**풀이**:

\(x = -1\)을 대입하면:
\[
3(-1)^3 - (-1)^2 + 4(-1) + 1 = -3 - 1 - 4 + 1 = -7
\]
우변: \(-7\) (확인됨)

\(x + 1 = t\)로 놓으면 \(x = t - 1\):
\[
3(t-1)^3 - (t-1)^2 + 4(t-1) + 1 = 3t^3 + at^2 + bt - 7
\]

좌변을 전개:
\[
3(t^3 - 3t^2 + 3t - 1) - (t^2 - 2t + 1) + 4(t - 1) + 1
\]
\[
= 3t^3 - 9t^2 + 9t - 3 - t^2 + 2t - 1 + 4t - 4 + 1
\]
\[
= 3t^3 - 10t^2 + 15t - 7
\]

따라서 \(a = -10\), \(b = 15\)

\(a + 2b = -10 + 30 = 20\)

**정답**: ②

### 08번

**지문**: 두 다항식 \(f(x)\), \(g(x)\)를 다항식 \(x^2 - x - 2\)로 나누었을 때의 나머지가 각각 \(x + 1\), \(3x - 1\)이다. 이때 \(f(x) - g(x)\)를 \(x + 1\)로 나누었을 때의 나머지는?

| 보기 | |
|:---|:---|
| ① 1 | ② 2 |
| ③ 3 | ④ 4 |
| ⑤ 5 | |

**풀이**:

\(f(x) = (x^2 - x - 2)Q_1(x) + x + 1\)

\(g(x) = (x^2 - x - 2)Q_2(x) + 3x - 1\)

\(f(x) - g(x) = (x^2 - x - 2)\{Q_1(x) - Q_2(x)\} + (x + 1) - (3x - 1)\)
\[
= (x^2 - x - 2)\{Q_1(x) - Q_2(x)\} - 2x + 2
\]

\(x^2 - x - 2 = (x + 1)(x - 2)\)이므로

\(f(x) - g(x)\)를 \(x + 1\)로 나눈 나머지: \(x = -1\) 대입

\(-2(-1) + 2 = 2 + 2 = 4\)

**정답**: ④

### 10번

**지문**: 삼각형 ABC의 세 변의 길이가 \(a\), \(b\), \(c\)이고, \(a^3 + b^3 + a^2b + ab^2 - ac^2 - bc^2 = 0\)을 만족시킬 때, 삼각형 ABC는 어떤 삼각형인가?

| 보기 | |
|:---|:---|
| ① \(a = c\)인 이등변삼각형 | ② \(b = c\)인 이등변삼각형 |
| ③ 한 변의 길이가 \(a\)인 정삼각형 | ④ 빗변의 길이가 \(b\)인 직각삼각형 |
| ⑤ 빗변의 길이가 \(c\)인 직각삼각형 | |

**풀이**:

\[
a^3 + b^3 + a^2b + ab^2 - ac^2 - bc^2
\]
\[
= (a^3 + a^2b) + (ab^2 + b^3) - (ac^2 + bc^2)
\]
\[
= a^2(a + b) + b^2(a + b) - c^2(a + b)
\]
\[
= (a + b)(a^2 + b^2 - c^2) = 0
\]

\(a + b > 0\) (삼각형의 변이므로)이므로 \(a^2 + b^2 - c^2 = 0\), 즉 \(a^2 + b^2 = c^2\)

빗변의 길이가 \(c\)인 직각삼각형이다.

**정답**: ⑤

### 12번

**지문**: 모든 실수 \(x\)에 대하여 다항식 \(P(x)\)가 \(\{P(x) + 1\}^2 = 4x^2 - 4ax - 8a^2 + 9\)를 만족시킬 때, 모든 \(P(1)\)의 값의 합은? (단, \(a\)는 상수)

| 보기 | |
|:---|:---|
| ① \(-5\) | ② \(-4\) |
| ③ \(-3\) | ④ \(-2\) |
| ⑤ \(-1\) | |

**풀이**:

양변의 차수를 비교하면 \(P(x)\)는 일차식이다.

\(P(x) = px + q\) (\(p, q\)는 상수, \(p \neq 0\))로 놓으면

\((px + q + 1)^2 = 4x^2 - 4ax - 8a^2 + 9\)

\(p^2 = 4\)이므로 \(p = \pm 2\)

- \(p = 2\)일 때: \((2x + q + 1)^2 = 4x^2 + 4(q+1)x + (q+1)^2\)

  \(4(q + 1) = -4a\), \((q + 1)^2 = -8a^2 + 9\)

  \(q + 1 = -a\)이므로 \(a^2 = -8a^2 + 9\), \(9a^2 = 9\), \(a = \pm 1\)

  \(a = -1\): \(q = 0\), \(P(x) = 2x\), \(P(1) = 2\)

  \(a = 1\): \(q = -2\), \(P(x) = 2x - 2\), \(P(1) = 0\)

- \(p = -2\)일 때: \((-2x + q + 1)^2 = 4x^2 - 4(q+1)x + (q+1)^2\)

  \(-4(q + 1) = -4a\), \((q + 1)^2 = -8a^2 + 9\)

  \(q + 1 = a\)이므로 같은 계산으로 \(a = \pm 1\)

  \(a = -1\): \(q = -2\), \(P(x) = -2x - 2\), \(P(1) = -4\)

  \(a = 1\): \(q = 0\), \(P(x) = -2x\), \(P(1) = -2\)

모든 \(P(1)\)의 값의 합: \(2 + 0 + (-4) + (-2) = -4\)

**정답**: ②

### 13번

### 19번

**지문**: 다음 그림과 같이 \(\angle ACB = 90^\circ\)이고 넓이가 \(6\)인 직각삼각형 ABC의 한 꼭짓점 C에서 선분 AB에 내린 수선의 발을 H라 할 때, \(\overline{CH} = 2\)이다. \(\overline{AH} = x\)라 할 때, \(x^3 - 5x^2 + x + 1\)의 값을 구하시오. (단, \(x > 3\))

**풀이**:

삼각형 ABC의 넓이가 \(6\)이므로:
\[
\frac{1}{2} \times \overline{AB} \times \overline{CH} = 6, \quad \overline{AB} = 6
\]

\(\overline{AH} = x\)에서 \(\overline{BH} = 6 - x\)

두 직각삼각형 AHC, CHB는 닮음이므로:
\[
\overline{AH} : \overline{CH} = \overline{CH} : \overline{BH}
\]
\[
x : 2 = 2 : (6 - x), \quad x(6 - x) = 4, \quad x^2 - 6x + 4 = 0
\]

\(x > 3\)에서 \(x = 3 + \sqrt{5}\)

\(x^3 - 5x^2 + x + 1\)을 \(x^2 - 6x + 4\)로 나누면:

\(x^3 - 5x^2 + x + 1 = (x^2 - 6x + 4)(x + 1) + 3x - 3\) ... (*)

(*)은 \(x\)에 대한 항등식이므로 \(x = 3 + \sqrt{5}\)를 대입하면:

\(x^2 - 6x + 4 = 0\)이므로

\(x^3 - 5x^2 + x + 1 = 0 + 3(3 + \sqrt{5}) - 3 = 9 + 3\sqrt{5} - 3 = 6 + 3\sqrt{5}\)

**정답**: \(6 + 3\sqrt{5}\)
